# 两条判别：PdM 还是 SHM

> 来源：一张双线判别对照表示意图（原始图片未归档，仅整理文字内容）
> 整理时间：2026-09-23

> [!warning] 保密标记
> 与前几帧同属一份内部材料（D1 系列，承 [销售定位-三层与可验证点.md](./销售定位-三层与可验证点.md)、[价值论证-三个问题用他自己的数.md](./价值论证-三个问题用他自己的数.md)）。含内部定价层级与竞品格局表述。**本仓库会 push 到 git remote**，入库前需确认可达范围或做去标识化处理。

**一句话**：这一帧是**进门前的分类闸门**——先把客户要做的到底是 PdM 还是 SHM 分清楚，**不然整场问的是别人的问题**。

"进门前"三字的分量：这不是技术内部的分类学，而是**销售动作之前的前置判断**。分错了，后面每一个问题（问什么信号、算在哪、怎么计量、报什么价、报告给谁看）都会错位——而这些错位在客户面前表现为"你根本不懂我这行"。

## 一、六维对照表

| | **设备预测性维护（PdM）** | **结构健康监测（SHM）** |
|---|---|---|
| **被监测对象** | 旋转 / 往复机械、电气、流程设备 | 桥梁、隧道、边坡、管廊、建筑、大坝 |
| **主信号** | 振动 / 电流 / 转速 / 温度 / 压力 | 模态频率 / 位移 / 应变 / 倾角 / 裂缝宽度 |
| **头号干扰** | **工况**（负载、转速、阀位、模式） | **环境**（季节、温度、湿度、交通荷载） |
| **时间尺度** | 分钟到月，**可能突发** | 月到年，**缓变为主** |
| **现场算在哪** | 多为**设备内一块小板** | 多为**现场一台边缘计算盒**（多路汇聚） |

五行里有三行直接回扣前面的技术笔记：

**(1) 头号干扰这一行，是两条线各自的理论主线。** PdM 的敌人是**工况**——这解释了 [在线原型库.md](./在线原型库.md) 为什么把"正常"拆成"正常·低负载 / 正常·高负载"多条原型，以及余弦相似度为什么必须对幅值免疫（负载改变整体幅值却不改变频率成分的形状）。SHM 的敌人是**环境**——这正是 [噪音问题-环境还是传感器.md](./噪音问题-环境还是传感器.md) 整帧的主题（支架热变形 vs 真实位移、昼夜周期特征）。**两边的"头号干扰"栏，恰好是两份笔记各自回答的那个问题。**

**(2) 时间尺度这一行，规定了自适应机制的能力级别。** "分钟到月，可能突发"意味着 PdM 需要处理快变工况切换（换工况仍须重新装机——[在线原型库.md](./在线原型库.md) 的边界）；"月到年，缓变为主"则是 SHM 的天然舒适区，也正是"受约束的在线学习"（预算上限 + 停学门 + 不新增类别）**最能发挥**的场景——缓慢漂移正是原型小步微调的设计目标。

**(3) 现场算在哪这一行，就是 [销售定位-三层与可验证点.md](./销售定位-三层与可验证点.md) 那句"两种形态别混"的表格版**：

| 形态 | 对应 | 硬件 |
|---|---|---|
| 设备内一块小板 | PdM（单台设备贴装） | MCU 级 |
| 现场一台边缘计算盒 | SHM（结构监测 / 多路汇聚） | 带 NPU |

⚠️ 与本系列一贯的**证据不得跨档**纪律一致：手上的体积 / 延迟实测属小板那一档，不能拿去支持边缘盒那一档的说法（边缘盒选型与报价仍在定）。

## 二、居中判据：看物理载体，不看行业名称

> **判据** 看**故障的物理载体**，不看**行业名称**。按行业分的直觉会出错 —— **高速公路的隧道风机是 PdM，同一个业主的隧道衬砌是 SHM。**

这是全帧最有价值的一句，它把分类依据从"**这是哪个行业的客户**"改成了"**要监测的那个东西是什么物理对象、坏起来是什么形态**"。

| 对象 | 谁在坏 | 载体 | 归属 |
|---|---|---|---|
| 隧道风机 | 轴承 / 叶轮（旋转机械） | 机械件退化 | **PdM** |
| 隧道衬砌 | 混凝土 / 结构本体 | 结构变形 | **SHM** |

**同一个业主、同一个项目、同一份合同里，两条线可以同时存在。** 所以"你们是设备监测还是结构监测"这个问题**按行业问不出答案**——只能按对象问。

这与 [噪音问题-环境还是传感器.md](./噪音问题-环境还是传感器.md) 的元论点（"对方问成一个问题，其实是两个"）是同一族手法：**先分类，再选战场**。区别在于那一帧拆的是**问题的两个侧面**，这一帧拆的是**两套产品线**。

实务含义：若不分清就进场，会出现两种典型错位——
- 对着结构客户讲振动包络解调（[包络解调.md](./包络解调.md)），对方毫无共鸣；
- 对着旋转机械客户讲多通道一致性、昼夜热致特征（[噪音问题-环境还是传感器.md](./噪音问题-环境还是传感器.md)），对方觉得你在讲另一个行业的事。

两种错位的后果都是同一句话：**"你整场问的是别人的问题。"**

## 三、左下：计量单位——"第一次对话就要说对"

> **设备按「台」· 结构物按「座 · 机房 / 柜」。单位定错，后面每一轮都在错的尺子上还价。**

四件事被这一栏同时锁死：

| 单位错位的连锁后果 | 说明 |
|---|---|
| **报价** | 按台报价 vs 按座报价，量级完全不同 |
| **覆盖率** | "覆盖 300 个点"是 300 台设备还是 300 座结构物？ |
| **成本摊薄** | [价值论证-三个问题用他自己的数.md](./价值论证-三个问题用他自己的数.md) 的"成本随点位线性放大"——**点位是什么**取决于单位 |
| **验收** | 验收标准写成"每台"还是"每座"，直接决定交付范围的争议 |

"**第一次对话就要说对**"是这一栏最重要的一句。理由是**锚定效应不可逆**：单位一旦在早期对话里被定成"台"，后面所有的报价、点位规模、运维预算讨论都在这个尺度上进行；等到发现该按"座"算时，客户已经拿计算器算了三轮，**改口径等于让他把前面的账全部重算——他不会有这个耐心，只会觉得你在涨价。**

与 [价值论证-三个问题用他自己的数.md](./价值论证-三个问题用他自己的数.md) 的同构处：那一帧是**让对方自己算**（举证责任转移），这一帧是**先把尺子定对**（否则他算得再认真也是错的数）。**先对齐单位，再谈价值；顺序反了，价值论证会反过来伤害你。**

## 四、右下：我们现在卖的是哪一层

> **第一层：付费分析 / 评估。先用离线分析换信任，报告本身可以变成招标依据。**
> 往后是按单元订阅、再往后是授权分成 —— **今天不展开。**

这一栏给出了**商业模式的当前锚点**，与 [销售定位-三层与可验证点.md](./销售定位-三层与可验证点.md) 的"技术三层"是**正交的另一条轴**——那张表讲**卖什么能力**（适应 / 运维 / 形态），这张表讲**以什么形式收钱**：

```
第一层（现在）：付费分析 / 评估
                └─ 交付"报告"，不交付"系统"
                └─ 目的：换信任；报告的副产品是成为客户的招标依据
第二层（往后）：按单元订阅
第三层（再往后）：授权分成
```

**"先用离线分析换信任"的分量**：这是把**技术验证的风险前置转移**——不要求客户先装一套系统、先改流程、先过验收，只要他给数据（或允许做一次评估），我们出一份报告。客户付出的成本极低，而我们的能力展示是完整的一次。这与 [噪音问题-环境还是传感器.md](./噪音问题-环境还是传感器.md) 里"让客户做一个已知扰动实验"的第四条是**同一种商业动作**——**把不确定的采购决策，换成一次低成本的、结果可判定的动作。**

**"报告本身可以变成招标依据"是最锋利的一处**：如果我们的报告被客户拿去写进了招标文件的技术要求，那么标书里的技术口径**就是我们写的**——这比任何一次讲标都有效，且**竞争中立于必然而非或然**。这也是为什么第一层值得做、甚至值得低价做：它买的不是这一单的钱，是**下一单的技术标准制定权**。

**"今天不展开"**是本系列第 N 次出现同一纪律——与 [销售定位-三层与可验证点.md](./销售定位-三层与可验证点.md) 的"⚠️ 证据不得跨档"、[噪音问题-环境还是传感器.md](./噪音问题-环境还是传感器.md) 的"环境侧这一帧不展开"同源：**能分清"现在讲到哪一层"本身就是专业度**。往后两层的定价结构、单元定义、分成比例都还没定，讲出来就是编。

## 五、知识点清单

1. **分类闸门**：PdM vs SHM 是**进门前**的前置判断，分错则整场都在答别人的题
2. **六维对照**：被监测对象 / 主信号 / 头号干扰 / 时间尺度 / 现场算在哪（+ 隐含的交付形态）
3. **PdM 的头号干扰是工况，SHM 的是环境**——两栏各自对应两份笔记的主线（原型库按工况分多条原型；噪音问题的热致漂移）
4. **时间尺度差规定机制级别**：PdM 分钟到月可能突发；SHM 月到年缓变为主，正是受约束在线学习的舒适区
5. **形态对照**：PdM → 设备内 MCU 级小板；SHM → 现场带 NPU 边缘计算盒（多路汇聚）——⚠️ 证据不得跨档
6. **核心判据：看故障的物理载体，不看行业名称**——同一业主的隧道风机是 PdM，隧道衬砌是 SHM
7. **计量单位第一次对话就要说对**：设备按台，结构物按座 / 机房 / 柜；单位定错 → 报价、覆盖率、成本摊薄、验收全线错位
8. **锚定不可逆**：口径改晚了，客户不会重算，只会觉得你在涨价 ⇒ 先对齐单位，再谈价值
9. **当前商业模式锚点**：第一层付费分析 / 评估（离线分析换信任，报告可成为招标依据）；按单元订阅与授权分成"今天不展开"
10. **报告的隐性收益**：技术口径写进客户招标文件 = 竞争从"或然"变"必然"，第一层值得低价做
11. **"今天不展开"是纪律而非回避**——不知道的说不知道，是本系列一以贯之的表述纪律
