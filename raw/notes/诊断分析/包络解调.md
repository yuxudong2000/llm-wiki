# 包络解调

> 来源：与 AI 的对话整理（围绕 `振动信号诊断四步流水线.md` 第③步展开）
> 整理时间：2026-09-23

---

## 一、它要解决的矛盾

轴承/齿轮的早期局部故障产生**极弱、极短、但周期性重复**的冲击，有两个致命性质：

1. **能量极弱** —— 淹没在噪声和机器其他部件（不平衡、对中、齿轮啮合）的强振动里；
2. **不直接出现在自己的特征频率上** —— 冲击是宽带的，真正的表现是**激发结构/传感器的某个高频共振模态**，让共振"振铃"。

所以原始频谱里**不会在 BPFO 处看到一根尖线**，看到的是一团**围绕共振频率 $f_c$ 的"草堆"（haystack）**——谱线以特征频率 $f_i$ 为间隔排列，密集到肉眼分不出来。

> [!quote] 核心
> **放弃载波 $f_c$，只保留调制节拍 $f_i$。** 这正是图里那句「要的信息在包络上，不在载波上」。

---

## 二、数学骨架

调制形式（$f_c$ 共振载波，$f_i$ 冲击重复率）：

$$x(t)=A(t)\cos(2\pi f_c t),\qquad A(t)=A_0+\sum_{k}A_k\cos(2\pi k f_i t+\varphi_k)$$

展开后取正频率部分：

$$X_+(f)=\frac{A_0}{2}\delta(f-f_c)+\sum_k\frac{A_k}{4}\Big[\delta(f-f_c-kf_i)+\delta(f-f_c+kf_i)\Big]$$

即：**原始频谱 = 一根位于 $f_c$ 的载波 + 对称分布在它两侧、间隔 $f_i$ 的边带梳**。

「解调」一词借自通信：**把这把梳子整体从 $f_c$ 搬回 0 Hz**，搬完之后原本挤在一起的边带就摊开成一根根清晰的谱线，位置正好落在 $f_i, 2f_i, 3f_i\dots$。这个新谱叫**包络谱（envelope spectrum）**。

### AM 收音机类比

| | 载波 | 消息 | 手段 |
|---|---|---|---|
| AM 广播 | 1 MHz 电台 | 音频 20 Hz–20 kHz | 二极管 + RC 包络检波 |
| 轴承诊断 | 结构共振 2–20 kHz | 故障冲击率 10–500 Hz | Hilbert 包络 + FFT |

**同一套数学。** 图里「冲击骑在高频共振上」画的就是这个调制结构。

## 三、Hilbert 解析信号：工程上怎么取包络

Hilbert 变换（本质是**全通 90° 相移器**）：

$$\hat{x}(t)=x(t)*\frac{1}{\pi t}=\frac{1}{\pi}\int_{-\infty}^{\infty}\frac{x(\tau)}{t-\tau}\,d\tau$$

频域上极简：$H(f)=-j\,\mathrm{sgn}(f)$，**幅度不动，相位移 90°**。

构造解析信号：

$$x_a(t)=x(t)+j\hat{x}(t)=A(t)\,e^{j\varphi(t)}$$

- **包络** $A(t)=|x_a(t)|=\sqrt{x^2(t)+\hat{x}^2(t)}$
- **瞬时相位** $\varphi(t)=\arctan(\hat{x}/x)$
- **瞬时频率** $\frac{1}{2\pi}\dfrac{d\varphi}{dt}$

离散实现：FFT → 负频率置零、正频率乘 2 → IFFT → 取模。

```python
import numpy as np
from scipy.signal import butter, filtfilt, hilbert

y = filtfilt(*butter(4, [f_lo, f_hi], 'bandpass', fs=fs), x)  # ① 带通
env = np.abs(hilbert(y))                                       # ② 解析信号取模
env = env - env.mean()                                         # ③ 去直流
spec = np.abs(np.fft.rfft(env * np.hanning(len(env))))         # ④ 包络谱
```

## 四、为什么必须先带通（成败关键）

Hilbert 包络精确的前提是 **Bedrosian 乘积定理**：

> 若 $A(t)$ 的频谱集中在 $|f|<a$、$\cos(2\pi f_c t)$ 的频谱集中在 $|f|>a$，二者**支撑集不重叠**，则 $\mathcal{H}[A\cos\omega_c t]=A\sin\omega_c t$。

即**载波必须与调制谱"频段分离"**。裸信号频谱连续铺开，根本不满足条件——直接对原始振动取 Hilbert，包络会剧烈抖动、毫无物理意义。**带通滤波不是可选项，是前提。**

### 带宽怎么定

双向约束：

- **下限**：带宽要能容纳边带梳本身，$B\gtrsim 2Kf_i$（$K$ 取 3–5 阶有效谐波），否则高阶边带被滤掉，包络谱只剩前一两根线；
- **上限**：不能宽到混进别的结构模态、齿轮啮合、电磁干扰；
- **前提**：共振模态本身带宽 $f_c/Q$ 要大于梳子跨度，否则"调制"这个模型本身近似失效。

### 自动选带：谱峭度与峭度图

人工试带很痛苦，Antoni 的**谱峭度（Spectral Kurtosis）**给了自动化方案，STFT 估计：

$$\mathrm{SK}(f)=\frac{\big\langle|X_w(t,f)|^4\big\rangle_t}{\big\langle|X_w(t,f)|^2\big\rangle_t^{2}}-2$$

含义是**"这个频率成分在时间上有多不平稳/多冲击"**，取值有明确物理边界：

| 信号类型 | SK 值 |
|---|---|
| 纯正弦（平稳、确定性） | −1 |
| 平稳高斯噪声 | 0 |
| 瞬态冲击（正是我们要的） | > 0 |

**Fast Kurtogram**（Antoni 2007）用 1/3-二叉树滤波器组在 (中心频率, 带宽) 平面扫一遍，取 SK 最大处作为带通参数，把 $O(N^2)$ 搜索降到近似 $O(N\log N)$。工程上基本是标准流程。

## 五、包络取出来之后的变体

### 1. 平方包络谱（SES）——通常优于普通包络谱

对 $|x_a(t)|^2$ 做 FFT。**循环平稳（cyclostationary）**视角：轴承故障信号是**二阶循环平稳**的，循环频率 $\alpha=kf_i$；其谱相关密度 $S_x^\alpha(f)$ 在 $\alpha=kf_i$、$f=\pm f_c$ 处出峰。**包络谱本质上是把 $S_x^\alpha(f)$ 沿 $f$ 在共振带内积分**得到的一维切片。

Antoni 的结论：当信号跨多个共振、或冲击幅度/间隔存在随机抖动时，单带普通包络谱是**次优**的——抖动会在包络里产生宽带"基座"，把离散峰淹掉；**平方包络对该基座不敏感**，离散谱线更锐利。这是现代算法默认用 SES 的原因。

### 2. Teager 能量算子（TEO）

$$\Psi[x]=\dot{x}^2-x\ddot{x},\qquad \text{离散：}\ \Psi[x_n]=x_n^2-x_{n-1}x_{n+1}$$

对 $A\cos\omega t$ 有 $\Psi=A^2\omega^2$，本质是"瞬时能量密度"，对冲击极其敏感、计算量极小（无需 FFT）。适合在线、嵌入式；缺点是抗噪差。

### 3. 倒谱（Cepstrum）

对**对数谱**再做一次 FFT。因为 $\log|X|=\log|H|+\log|E|$，**把卷积变成加法**，周期性边带族在倒谱域变成一根位于"倒频率" $T_i=1/f_i$ 的尖峰。共振带太宽、没法用带通隔离时是保底方案（编辑倒谱还能反重构信号）。

### 4. 解卷积类：MED / MOMEDA

**MED（最小熵解卷积）**用逆滤波器最大化输出峭度，把被共振"抹钝"的冲击重新锐化；**MOMEDA** 直接瞄准指定周期 $T$。常放在带通**之前**，提高峭度图选带的可靠性。

### 5. 循环谱 / 谱相干（最一般形式）

直接估计二维谱相关密度 $S_x^\alpha(f)$ 或谱相干 $\gamma_x^\alpha(f)$，横轴谱频率、纵轴循环频率。**包络解调只是它在 $f\approx f_c$ 处的一维切片。** **Fast Spectral Correlation**（Antoni）让它可算，代价是计算量。**Infogram**（2016）把峭度换成平方包络谱的负熵，专门对付"有冲击但不峭"的场合。

### 6. 工业界同族实现

| 名称 | 内核 |
|---|---|
| 冲击脉冲法 SPM | ~32 kHz 谐振测 dB 值 |
| 高频共振技术 HFRT | 共振带解调 |
| 共振解调 | 共振带解调 |

名字不同，**内核都是"在共振带上解调包络"**。

## 六、参数与常见坑

| 坑 | 表现 | 对策 |
|---|---|---|
| **带通选错** | **头号失败原因**，包络谱一片平 | 谱峭度/峭度图/Infogram，别手拍 |
| **低通截止频率** | 太高残留载波、太低削掉高阶谐波 | 截止 $<f_c$，且能过 3–5 阶 $f_i$ |
| **Hilbert 端点效应** | 首尾包络发散 | 镜像延拓/加窗；Hilbert 是全局算子，非因果 |
| **离散干扰谱线** | 50 Hz、邻机、齿轮啮合也在包络谱出峰 | 看是否成**谐波族**，孤立线一律排除 |
| **滚动体滑移** | 真实 BPFO 与公式值差 1–2%，高阶峰变钝/劈裂 | 允许容差；用阶次跟踪拉直（第④步） |
| **速度波动** | 整片包络谱峰被抹平 | 角域重采样 → 阶次域 |
| **早期故障太弱** | 看不见 | 同步平均、增加采样时长、上 AE 传感器（100 kHz–1 MHz） |
| **采样率不足** | 根本没采到共振带 | 采样率覆盖 $f_c$ 的 2–3 倍，常需 10–50 kHz+ |

**降采样技巧**：带通后解析信号的复包络带宽 $\le B/2$，所以**可以大幅降采样**再算包络谱，计算量降一两个数量级。

## 七、包络谱怎么读（诊断规则）

横轴单位 Hz，核心原则是**找"谐波族"而不是找单根线**：

| 现象 | 推断 |
|---|---|
| $k\cdot f_{BPFO}$ 谐波族 | 外圈故障 |
| $k\cdot f_{BPFI}$ 谐波族 **+ 两侧 $f_r$ 间隔边带** | 内圈故障（故障随轴转动进出承载区，被 1× 转频调制） |
| $k\cdot f_{BSF}$，常伴 $f_{FTF}$ 边带 | 滚动体故障 |
| $f_{FTF}$ 及其谐波 | 保持架故障 |
| $k\cdot f_{mesh}$ 及其 $f_r$ 边带 | 齿轮故障（边带间距对应哪根轴，就坏在哪根轴上） |
| 1× 转频高 | 不平衡 |
| 2× 转频高 | 对中不良 / 轴弯曲 |
| 大量转频谐波（松动特征） | 机械松动 |

判读时还要看**峰的形态**：外圈峰谐波能延伸到很高阶且锐利；内圈峰到 3–4 阶后开始模糊（调制 + 滑移）；只有一根孤立线且不和谐，基本是干扰。

## 八、包络解调会同时提取正常信号和冲击信号吗？

**会。** 包络解调是**搬家人，不是守门人**——它不筛选，带通带内的一切都被一视同仁地解调出来。分开"正常"和"故障"的不是解调本身，而是它们在**包络谱上的形态差异**。这与 AM 收音机相同：检波器把音乐和远处雷声**都**输出，你的耳朵靠"音乐连续、雷声脉冲"来区分。

| 环节 | 对"正常信号" | 对"冲击信号" |
|---|---|---|
| ① 带通滤波 | 带外**物理滤除**，带内保留 | 保留 |
| ② 取包络 | 无差别搬运，**不筛选** | 无差别搬运 |
| ③ 包络谱 | 落成**平滑基底（floor）** | 落成**离散谐波族** |

**"正常信号"的三档去向**：

- **低频正常成分**（1× 转频、不平衡、对中不良）——不在共振带里，**被带通直接滤掉**。这部分确实没被提取，但功劳属于带通而非解调。
- **带内平稳宽带噪声**（背景噪声、健康轴承自身振动）——**被提取了**，但没有周期性幅度调制，只贡献一根**平坦基底**。
- **带内其他周期源**（齿轮啮合、电磁力、邻机冲击）——**也被提取了，且同样出离散峰**。这是主要干扰源，只能靠**频率坐标对不上**来排除。

### 更本质的说法：平稳 vs 循环平稳

$$x(t)=\underbrace{x_{\text{cyclo}}(t)}_{\text{确定性周期调制}}+\underbrace{n(t)}_{\text{平稳随机}}$$

- **平稳成分** $n(t)$ 的循环谱**只在循环频率 $\alpha=0$ 处非零**；
- **循环平稳成分**（故障冲击）在 $\alpha=kf_i$ 处有一串离散值。

包络谱近似是 $S_x^\alpha(f)$ 在共振带内沿 $f$ 的积分，于是：

$$S_n^\alpha(f)=0\quad(\alpha\neq 0)\ \Longrightarrow\ \text{平稳信号对所有非零循环频率的贡献理论上为零}$$

这就是"包络解调能自动剔掉平稳正常信号"的理论依据。但**这是理想情况**——数据长度有限、加窗导致谱泄漏，滤波器非理想、有瞬态，冲击本身滑移抖动导致离散峰展宽，都会让平稳成分"渗"到 $\alpha\neq 0$，形成那个基底。所以工程上永远是**提高对比度**，而不是**彻底提取**。

### 三个实践含义

1. **判读看"离散性"，不是看"有没有峰"**：是否构成 $k f_{BPFO}$ **谐波族**、是否高于**局部基底**足够多、是否有预期的**调制边带**。Infogram 本质就是量化"这块谱有多不像高斯噪声"。
2. **基底是 SNR 的分母**：健康轴承和背景噪声构成的基底决定**能检出多弱的冲击**。提高灵敏度要么抬高峰（解卷积锐化）、要么压低基底（同步平均、延长采样）。
3. **可用健康基线做显式对照**：采集同型号健康轴承的包络谱作基线，做相减或包络谱自相关对比，把"正常信号"从分母变成已知量 → 显著改善早期故障检出。这也是很多数据集专门提供 baseline 工况的原因。

> [!quote] 一句话
> 包络解调是**搬家人，不是守门人**。真正做筛选的是两处：前置**带通**决定哪些源能进来，后置**判读规则**决定哪根峰可信。

## 九、在整条链路中的位置

- **②特征频率** 提供**先验的、可计算的目标坐标**——要在包络谱上找什么，全靠它；
- **③包络解调** 是**唯一能把那个坐标从噪声里抬出来的线性算子**——所以属「前端」：可解释、无需训练数据、换台机器照样用；
- **④阶次跟踪** 补③的短板：③假设转速恒定，转速一变包络谱就抹平，必须换到角域。

**③和④解决两个不同问题——③对抗"信噪比"，④对抗"非平稳"。** 它们之上（在线退化跟踪、剩余寿命、变工况自适应）才是数据驱动方法该发力的地方。**前端决定了后端的上限**，信号没洗干净，再大的模型也是在噪声上过拟合。
