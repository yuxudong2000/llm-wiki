# 答不上来的时候：三步，以及今天带走什么

> 来源：一张收尾话术设计示意图（原始图片未归档，仅整理文字内容）
> 整理时间：2026-09-23

> [!warning] 保密标记
> 与本系列前几帧同属一份内部材料（D1 系列），且是本批材料的**收尾帧**。含内部销售流程与待补事项清单。**本仓库会 push 到 git remote**，入库前需确认可达范围或做去标识化处理。

**一句话**：这一帧收束整批材料——**前面所有帧教的是"怎么说"，这一帧教"说不上来时怎么办"**，并把整批材料压缩成一张可带走的清单。

## 一、三步

> ① **不猜** → ② **给一个真实的替代物** → ③ **记下原句，回传，并且真的回去查**

### ① 不猜

前几帧反复出现的纪律（[销售定位-三层与可验证点.md](./销售定位-三层与可验证点.md) 的"没测过就说没测过"、[竞品路线B-经典统计五件套.md](./竞品路线B-经典统计五件套.md) 的"不比精度就明确不比"、[噪音问题-环境还是传感器.md](./噪音问题-环境还是传感器.md) 的"环境这块我不猜"）。这里是它**最纯粹的形态**——没有任何技术内容，只是一条行为规范。

### ② 给一个真实的替代物

这是三步里最容易被做错的一步，也是**唯一有技术含量的一步**。替代物必须是**真的**——

| | 做法 | 性质 |
|---|---|---|
| ✅ **真实的替代物** | "这个数字我今天给不了，但**机制上它是这样**……"或"这条我们**在软件层验证过**，**硬件上没做**" | 给的是**边界内的确定信息** |
| ❌ 假的替代物 | 给一个像模像样的量级、引用一个记不清来源的结论、嘴上说"大概" | 用一个猜测填掉空位 |

替代物的"真实"体现在：**它同样是可验证的、或者至少是明确标注了性质的**（[神经形态芯片.md](./神经形态芯片.md) 的"软件层验证 ≠ 硬件验证"、[应答设计-故障会不会被学进去.md](./应答设计-故障会不会被学进去.md) 的"参考实现已核 ≠ 出货端已核"）。"不猜" 不等于 "什么都不给"——**不猜的是那个未知量，给的是那件事在已知范围内的完整结构**。

### ③ 记下原句，回传，并且真的回去查

三个动作各有各的必要性：

| 动作 | 为什么必做 |
|---|---|
| **记下原句** | 转述会失真——客户的原话里含他的关切点与用词习惯，转述给内部时会被"翻译"成我们的语言，于是答复也可能答偏 |
| **回传** | 团队才知道**客户实际问到了哪里**——这是最有价值的产品需求来源（比内部拍脑袋想的场景真实得多） |
| **真的回去查** | 承诺的兑现率决定这套话术能不能再用第二次。**说"回去给"然后没给，比当场编一个还糟**——编的当场被识破只是丢一次脸，"回去给"没给是**主动建立了一个可证的失信记录** |

> 「**这个我不确定，我不猜。记下来回去确认后给您准确答复。**」

**"这句话永远不会说错"** 是这一栏的落点。前面几帧里所有话术都有适用条件——"先查采集还活着没有"只在客户确实有采集健康问题时好用，"我们一个数字都不给"需要客户愿意回答。**只有这一句是无条件的**：任何场合、任何人、任何问题，说它都不会错。

> **"今天讲的所有东西里，只有这一条是百分之百可执行的。"**

这句自评很重——它等于承认前面所有帧都需要判断力（判断客户属于哪条线、判断问哪个问题、判断讲到哪一层），而**这一条不需要任何判断，照做即可**。反过来读：这也是一份**诚实的能力清单**——我们给的是"方法 + 边界"，不是"标准答案手册"。

## 二、左下：带走三样

> ① **一页地图卡**：三层 · PdM/SHM 判别 · 计量单位
> ② **一页问题卡**：经济论据那三个问题 + 采集健康那一问
> ③ **一句话：先问采集还活着没有**

三样恰好是整批材料的三条线，而且**每样都是一页纸或一句话的体量**：

| 携带物 | 来源帧 | 性质 |
|---|---|---|
| **地图卡**（三层 · PdM/SHM · 计量单位） | [销售定位-三层与可验证点.md](./销售定位-三层与可验证点.md)、[两条判别-PdM还是SHM.md](./两条判别-PdM还是SHM.md) | **定位**——知道自己站在哪、对面是谁 |
| **问题卡**（经济论据三问 + 采集健康一问） | [价值论证-三个问题用他自己的数.md](./价值论证-三个问题用他自己的数.md)、[噪音问题-环境还是传感器.md](./噪音问题-环境还是传感器.md) | **提问**——知道该问什么 |
| **一句话**（先问采集还活着没有） | [噪音问题-环境还是传感器.md](./噪音问题-环境还是传感器.md)、[销售定位-三层与可验证点.md](./销售定位-三层与可验证点.md) | **一个动作**——最坏情况下也能建立专业形象 |

**"一页"和"一句话"是关键设计**：面对客户的是一线的人，不是材料作者。**给十页方法论的后果是当场一页都想不起来**；给一页卡 + 一句话，才有可能真的用出来。

而"**先问采集还活着没有**"被单独列成第三样，是因为它是**全批材料里唯一一个当场可执行、成本极低、且立刻建立专业形象的动作**——[销售定位-三层与可验证点.md](./销售定位-三层与可验证点.md) 已给过它的社交收益定性："第一个问『这些点位的数据最近还在更新吗』的人，会被当成内行"。这句话甚至不需要先分清 PdM 还是 SHM——**两条线通用**。

## 三、右下：今天没讲、后面要补的

> - **客户的世界**（谁签字、钱走哪个科目）—— **要靠你们讲给我**
> - 什么线索值得投入、什么时候礼貌收尾
> - 怎么当面算账 · 技术对接要收什么 · **边缘盒那一档的选型与报价**

四项空白，**性质各不相同**——这是这一栏最值得读的地方：

| 待补项 | 缺口性质 | 谁来补 |
|---|---|---|
| **客户的世界**（谁签字、钱走哪个科目） | **情报缺口**——我们不可能自己知道 | ⚠️ **一线反向输入给我们** |
| 什么线索值得投入 / 什么时候礼貌收尾 | **判断力缺口**——需要实战经验，无法文档化 | 一线（隐性知识） |
| 怎么当面算账 | **方法缺口**——可文档化，待写 | 我们（材料作者） |
| 技术对接要收什么 | **流程缺口**——可文档化，待定 | 双方 |
| **边缘盒那一档的选型与报价** | **事实缺口**——东西还没定 | 时间（选型定下来才有） |

**第一条"要靠你们讲给我"是整批材料里唯一一次方向反转**：前面所有帧都是我们教一线怎么说；这一条承认**有一个领域是我们教不了的，必须由一线反过来喂给我们**。

这恰好印证了 [价值论证-三个问题用他自己的数.md](./价值论证-三个问题用他自己的数.md) 底部蓝框那条隐性收益——**"他回答的过程会顺带告诉你：几个系统、谁在管、哪套最让他头疼、预算从哪出"**。三个提问表面是说服设计，实质同时是**情报采集装置**；这里点明了它采集的信息最终要**回流**到哪里。

**"边缘盒那一档的选型与报价"再次出现**（前见 [销售定位-三层与可验证点.md](./销售定位-三层与可验证点.md) 的"⚠️ 证据不得跨档"）——这是整批材料**第三次**提到同一处未定项，可见它是当前最要紧的事实缺口。

## 四、最后一句：关于「这个还没定」

> **今天有几个地方我说了「这个还没定」。那不是没准备好，是现在真实的状态 —— 在客户面前也是同一个说法。一起把它定下来，比各自猜一个版本快得多。**

这是整批材料的**元声明**，也是最有分量的一句。

**"那不是没准备好，是现在真实的状态"** —— 把"未定"从**能力缺陷**重新定性为**事实陈述**。这是本系列一贯手法的又一次运用：把"我们是不是不行"（能力比较问题，可争）转化为"这个东西现在确实还不存在"（结构性事实，不可争）。同构于：

| 帧 | 转换 |
|---|---|
| [噪音问题-环境还是传感器.md](./噪音问题-环境还是传感器.md) | 从"算法好不好" → "单通道信息论上不可解" |
| [竞品路线B-经典统计五件套.md](./竞品路线B-经典统计五件套.md) | 从"竞品做得差" → "竞品结构上缺这块" |
| [销售定位-三层与可验证点.md](./销售定位-三层与可验证点.md) | 从"能力差距" → "结构缺失" |
| **本篇** | 从"没准备好" → "现在真实的、尚未定下来的状态" |

**"在客户面前也是同一个说法"** 是最关键的一句——它把前面所有帧的表述纪律（没测过就说没测过、不猜、不比精度）统一成一条**内外一致原则**：**对内的未定事项清单，和对外的说法，必须是同一份。** 不存在"内部知道没定、对外讲成已定"的空间。一旦开了这个口子，前面所有"你能自己验证"的设计都失去地基——因为客户能验证的前提是**我们说出口的都是真的**。

**"一起把它定下来，比各自猜一个版本快得多"** 是这条纪律的**效率论证**（不只是道德论证）：

```
各自猜一个版本 → N 个人对客户讲出 N 个不同的规格 → 客户在不同场合听到不同答案
                                                    → 信任崩塌 + 后续必须回头纠正 N 次
公开说"还没定" + 一起定 → 一次对齐，之后所有人讲同一个版本
```

所以"承认没定"不是谦卑，是**收敛速度最快的一条路径**。这与 [应答设计-故障会不会被学进去.md](./应答设计-故障会不会被学进去.md) 的立场完全一致：**承认边界是加分不是减分。**

## 五、知识点清单

1. **三步法**：① 不猜 → ② 给一个真实的替代物 → ③ 记下原句、回传、并且真的回去查
2. **替代物必须是真的**——"不猜"不等于"什么都不给"，给的是**已知范围内的完整结构**（如"软件层验证过、硬件没做"）
3. **记原句 / 回传 / 真去查**三个动作各有必要性；**说"回去给"然后没给，比当场编一个还糟**（把一次失信变成可证的失信记录）
4. **「这个我不确定，我不猜。记下来回去确认后给您准确答复。」永远不会说错**——全批材料里**唯一百分之百可执行**的一条，不需要任何判断力
5. **带走三样**：一页地图卡（三层 · PdM/SHM · 计量单位）、一页问题卡（经济三问 + 采集健康一问）、一句话（先问采集还活着没有）
6. **"一页 / 一句话"是刻意的体量设计**——给十页方法论的后果是当场一页都想不起来
7. **"先问采集还活着没有"单列成第三样**，因为它当场可执行、成本极低、立刻建立专业形象，且 **PdM / SHM 两条线通用**
8. **待补四项性质不同**：客户的世界（情报缺口，⚠️一线反向输入）· 线索判断与收尾时机（判断力缺口）· 当面算账（方法缺口）· 技术对接收什么（流程缺口）· 边缘盒选型与报价（事实缺口，第三次出现）
9. **"要靠你们讲给我"是全批唯一一次方向反转**——承认有一块我们教不了，必须由一线喂回来
10. **「还没定」不是没准备好，是现在真实的状态**——把"未定"从能力缺陷定性为事实陈述（同族转换第 N 次）
11. **内外一致原则**：对内的未定清单与对外的说法必须是同一份；开了口子则"客户能自己验证"整个设计失去地基
12. **效率论证**：各自猜一个版本 → N 个人讲出 N 个规格 → 回头纠 N 次；公开说"还没定" + 一起定 = 收敛最快
