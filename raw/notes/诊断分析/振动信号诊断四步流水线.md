# 振动信号故障诊断四步流水线

> 资料形态：一张流程示意图（2668×808 PNG）

**一句话**：这是一条旋转机械（轴承/齿轮）故障诊断的信号处理链——四步串成流水线，底部两块说明"为什么必须有第四步"以及"这套东西在系统里是什么定位"。

---

## 一、图面还原

```
① 原始振动波形  →  ② 特征频率  →  ③ 包络解调  →  ④ 阶次跟踪
```

| 步骤 | 图上的关键句子 |
|---|---|
| ① 原始振动波形 | 高频共振 + 周期性敲击 |
| ② 特征频率 | 坏在哪个部位 → 能量出现在一个算得出来的频率上；**查公式算的，不是学出来的** |
| ③ 包络解调 | 故障敲击骑在高频共振上——**要的信息在包络上，不在载波上** |
| ④ 阶次跟踪 | 把「按时间采样」重采样成「按转角采样」；**换坐标系——不是换算法** |

**左下块（为什么必须有第四步）**
> 转速一变，前面几步的位置会跑。同一个故障，转速从 1500 rpm 变到 1800 rpm——在时间域，那根谱线跟着移动（跟转速成正比）；在转角域，它还在同一个位置。

**右下块（定位声明）**
> 这三件套是「前端」，不是对手。它们把信号整理干净；我们做的是后面那一段——整理干净之后，怎么在线跟住变化。
> ⛔ 不要摆「我们用 AI 所以不需要这些」的姿态。

## 二、四个步骤展开

### ① 原始振动波形：调制结构

传感器采到的是**被周期性冲击调制过的高频振荡**：

- 轴承滚道点蚀/剥落、齿轮断齿 → 每转经过一次产生一次**冲击**；
- 冲击是**宽带且极短**的，会激发轴承座/传感器/结构的某个**共振模态** $f_c$（通常几 kHz–几十 kHz）；
- 于是信号长成：以共振频率 $f_c$ 为载波、以冲击重复率 $f_i$ 为节拍的一串衰减振荡。

$$x(t)=A(t)\cos(2\pi f_c t),\qquad A(t)=A_0+\sum_k A_k\cos(2\pi k f_i t+\varphi_k)$$

**关键**：早期故障冲击非常弱，直接看时域或做常规 FFT，谱线会被噪声和其他部件（不平衡、对中、啮合）淹没 → 必须往下走三步。

### ② 特征频率：把谱线翻译成部件

轴承各部位故障频率由**几何运动学算出**（$f_r$ 转频、$n$ 滚珠数、$d$ 滚珠直径、$D$ 节径、$\alpha$ 接触角）：

| 故障位置 | 公式 | 典型阶次 |
|---|---|---|
| 外圈 BPFO | $\frac{n}{2}f_r\big(1-\frac{d}{D}\cos\alpha\big)$ | 3–6× |
| 内圈 BPFI | $\frac{n}{2}f_r\big(1+\frac{d}{D}\cos\alpha\big)$ | 5–9× |
| 滚动体 BSF | $\frac{D}{2d}f_r\big[1-(\frac{d}{D}\cos\alpha)^2\big]$ | 2–4× |
| 保持架 FTF | $\frac{1}{2}f_r\big(1-\frac{d}{D}\cos\alpha\big)$ | ≈0.4× |

齿轮：$f_{GMF}=z\cdot f_r$，故障表现为**以转频为间隔的边带**（边带间距定位到具体哪根轴）。

图里"**查公式算的，不是学出来的**"是立场声明：这些数来自轴承手册和几何运动学，是**物理先验**，不是从数据拟合的 → 可解释、可迁移、可交叉验证。

### ③ 包络解调：要的信息在包络上，不在载波上

三步走：

1. **带通滤波**——围绕共振带 $f_c$ 选一段，避开低频干扰；
2. **Hilbert 求包络**——解析信号 $x_a(t)=x(t)+j\mathcal{H}\{x(t)\}$，取模 $|x_a(t)|$；
3. **对包络做 FFT**——得到**包络谱**，谱峰落在 BPFO/BPFI 等特征频率上。

直觉：**载波只负责把信号抬到干扰少的频段，信息全部编码在包络的重复节拍里**。

⚠️ 带通不是可选项：Hilbert 取包络精确的前提是**载波与调制谱频段分离**（Bedrosian 乘积定理），裸信号是宽带的，直接取包络无物理意义。

同一族其他方法：平方包络谱（SES）、Teager 能量算子（TEO）、倒谱、**谱峭度/快速峭度图**（自动选共振带）、最小熵解卷积（MED/MOMEDA）。

### ④ 阶次跟踪：换坐标系，不是换算法

**问题**：FFT 假设平稳。转速从 1500 → 1800 rpm 时，故障谱线 $f=k f_r$ **跟着转速线性移动**，频谱被抹开、峰变矮变胖 → ③在变转速下失效。

**解法**：不按等时间采样，改按**等转角采样**：

$$\theta(t)=\int_0^t \omega(\tau)\,d\tau,\qquad \text{固定 }\Delta\theta,\ \text{可变 }\Delta t$$

再做 FFT，横轴变成**阶次（order）**（转频的倍数）→ 无论转速怎么变，$k$ 阶故障**永远停在同一位置**。

**"换坐标系——不是换算法"**：内核仍是 FFT/包络那套，变的只是**自变量从 $t$ 换成 $\theta$**——一个变量替换，不是新算法。

实现层面：

| 方式 | 说明 |
|---|---|
| 硬件同步采样 | DDS 用转速脉冲直接驱动采样时钟 |
| 计算式阶次跟踪 COT | 先采样后插值重采样（三次样条/Lagrange），用键相脉冲拟合 $\theta(t)$ |
| 无键相 tacholess | 从振动信号自身时频脊线估瞬时转速；无转速传感器时的方案，偏研究 |
| 收益 | 谱线对齐、长时同步平均提 SNR、阶次瀑布图跟踪故障演化 |

## 三、核心知识点清单

1. **调制模型**：故障冲击（低频重复）→ 激发结构共振（高频载波）→ 包络解调取回重复率。整条链路的物理骨架。
2. **运动学特征频率公式**：BPFO/BPFI/BSF/FTF、齿轮啮合频率与边带。物理先验，可解释、可迁移。
3. **Hilbert 解析信号 / 包络 / 带通选带**：把弱冲击从强噪声里捞出来的标准手段。
4. **平稳性假设及其失效**：FFT 假设平稳；变转速破坏它；频率随转速线性漂移。
5. **角域重采样 / 阶次分析**：$\theta(t)=\int\omega dt$ 的变量替换，把频率轴换成阶次轴，使转速变化"消失"。
6. **方法论分工**：②解决"目标坐标"，③对抗"信噪比"，④对抗"非平稳"；前端的信号调理质量直接决定后端模型的上限。

## 四、定位与边界

**三件套（①②③）= 前端**，职责是"把信号整理干净"，基于物理先验、无需训练数据、可解释可迁移。

**第四步也属于前端**——它是给三件套打的补丁，专修"非平稳"这块短板，让后端拿到转速归一化过的干净信号。

**真正属于后端的**是阶次域**之后**那一段：在线退化跟踪、剩余寿命预测、变工况自适应、多源融合。

⚠️ **常见误读**：把这句话读成"AI 无用"或"经典方法过时"都是错的——图里的原意是**互补**：经典方法提供强归纳偏置和可解释的物理坐标系，AI 处理残余的非线性、变工况与在线更新。
