## 核心脉络

**前端三件套 + 补丁（物理先验路线）**

```
① 原始波形（高频共振 + 周期性敲击）
      ↓  调制模型：故障冲击激发结构共振
② 特征频率（BPFO / BPFI / BSF / FTF / GMF，查公式算的）
      ↓  先验坐标：要在哪个频率上找
③ 包络解调（带通 → Hilbert → 包络谱）
      ↓  对抗信噪比：把坐标从噪声里抬出来
④ 阶次跟踪（时间域 → 转角域重采样）
      ↓  对抗非平稳：转速归一化
后端：在线退化跟踪 / 剩余寿命 / 变工况自适应
```

**一句话**：①②③ 是「前端」，负责把信号整理干净；④ 是给前端补的"非平稳"补丁；真正的数据驱动活儿在阶次域之后。

**深度学习路线（重构式异常检测，数据驱动）**

```
大量正常序列 → 编码器(LSTM) → 瓶颈(压缩摘要) → 解码器(LSTM) → 重建序列
                                                        ↓
新输入 x ────────────────→ 同一套(训练好权重的)网络 → 重建 x̂
                                                        ↓
                                    误差 = distance(x, x̂)  → 超阈值判异常
```

**一句话**：不依赖物理先验，靠"只在正常数据上学会压缩还原"的网络，把重构误差当异常分数；换骨架（LSTM/CNN/GNN/Mamba）、换目标（重构距离/概率/超球紧凑性）可以派生出一整族方法，但都要面对"正常数据比故障标注更贵""变工况往往要重训"两个结构性成本。

**骨架维度的三种归纳偏置**：Conv-AE 假设异常是**局部固定形状**的模式（STFT 频谱图 + CNN，强局部弱长时）；GNN 假设异常是**打破测点间关系**的模式（节点=测点，边=相关性，对 SHM 多测点网络最相关）；Mamba/SSM 假设异常是**打破一份被压缩记住的长期状态**的模式（线性状态递推，可并行训练，LMU 可推导版可解释）。三者是三种不同假设，不是精度高低的比较。

**两条路线对照**：前端强先验、成本固定、能定位故障部位；深度学习弱先验、成本随点位放大、只给异常分数不回答"坏在哪"。互补而非替代。

**三条技术路线的全景定位**（同一份竞品材料的 D1 系列）：

| 路线 | 代表方法 | 训练需求 | 核心成本 / 短板 |
|---|---|---|---|
| 竞品路线 A（深度学习） | LSTM-AE、Conv-AE、GNN、Mamba/SSM | 需 GPU 训练 | 标注成本高、域漂移要重训、成本随点位线性放大 |
| 竞品路线 B（经典统计） | 马氏距离、PCA 残差、OC-SVM、孤立森林、控制图 | **不需要训练**，闭式解 | 控制图用固定控制限，对**基线缓慢漂移**无能为力（误报堆积） |
| 自研线 | 在线原型库（K 条典型状态 + 余弦 argmax + 拒识），底层用 Legendre/LMU 等 | 不需要训练，闭式/增量；码本由初始化 + 在线更新得到 | 卖点：输出**带语义的状态**、边界随时间自适应、库规模恒定；限制：**只报"没见过"不报"故障"**、不新增类别（无开集能力）、只能跟缓慢漂移 |

两条竞品线的共同缺口是**"基线会随时间缓慢变化怎么办"**——深度学习路线靠离线重训（有周/月级延迟），经典统计靠人工每季度重画控制限，自研线把差异化落在这里：**胜出原型按小步长做在线微调**（受预算上限 + 停学门约束）。

**硬件维度：神经形态是可选路径，不是必要前提**。自研线的两件核心机制——argmax 取冠军（赢者通吃路由）、胜出原型小步微调（在线漂移自适应）——恰好是**局部、无需梯度**的操作，与神经形态芯片的原生原语（侧抑制 WTA、局部权重更新）计算形态对齐，理论上可映射过去；但目前只做到**软件层映射验证**，硬件验证未做，现在实际交付的是**普通 MCU 和网关**。且多数神经形态芯片是"推理专用、不能改片上权重"，能否承载"在线漂移自适应"高度依赖具体选型（Akida/Loihi 2 支持片上学习，多数其他芯片不支持）。关键纪律：**"可以映射" ≠ "更适合"**——兼容性声明，不是优越性声明。

**「余弦 · argmax」的两个操作别混**：argmax 选冠军（**永远不会返回"没有"**），阈值 $\tau$ 决定"够不够像"——后者才是「报没见过」的唯一开关。$\tau$ 取正常验证集"最高相似度"的**低分位**（与重构误差取高分位方向相反），且与原型数 $K$ 强耦合，装机改类别后必须重校。

**在线自适应其实有两条独立判据**（承《应答设计》）：**匹配半径**（相似度低于 $\tau$ → 报「没见过」）与**漂移预算**（偏移速度超预算 → 隔离）。两条可同时不触发——新样本"小、慢、还在半径内、变化也落在预算内"时会被当正常漂移吸收，**而这恰是缓发早期故障的形态，也是预测价值最大的阶段**。这是**结构性权衡**（容忍正常漂移与检出缓发早期故障在数学上是同一现象），可靠调节半径/预算的松紧移动工作点，无法彻底分开；且该结论是**机制推理，不是实测**。

**两级架构与容量上限**：K 槽工作记忆（短期候选缓冲）+ N 条持久库（长期原型）。N 到顶后超限输入被**静默并入最近一条、返回值同形**（外部不可观测）；**加大 N 只能推后临界点，端侧资源有界 ⇒ 推后 ≠ 消除**；可选 opt-in「到顶就拒绝」把它换成可观测的显式拒绝。⚠️ 注意命名：本篇《在线原型库》的 K = 原型条数，《应答设计》的 K = 工作记忆槽数、N = 持久库条数，对照时勿混。

**可复用经验：对外表述的事实核查纪律**——凡是要对外讲的技术优势，都必须能追溯到具体做过的实验及其实际证明的命题：
- "打平"（非劣性）≠"更准"（优越性），没做过的检验不能用直觉补；
- 没测过就说没测过（GNN："没跑过，回去给"）；
- 已流传的夸大说法要主动纠正（"CMAPSS 超 SOTA"是假的）；
- 具体数字走核实流程，现场只给量级；
- 不比精度就明确不比（经典统计一帧反复重申"不含任何精度对比"），并划清能力边界（跟缓慢漂移 ≠ 能扛换工况）。

**可复用经验：沟通纪律**——尊重对手的事实基础（经典方法免训练、跑得快，很多场景确实够用），开口否定客户现用系统会当场失去对方；一次演示只留一个记忆点（"那条线会自己挪"）。

**可复用经验：面对最难质疑的分层应答**（承《应答设计》）——把"会不会把故障学进去"这类听起来无法证伪的质问，翻译成**可判定的几何状态**（半径外/越预算/半径内不增长）。应答分三层，按追问深度释放：层1 讲机制；层2 对工程师补**可验证性**而非承诺（"不是我们承诺它不会，是你可以查它有没有"）；层3 被追到具体数字时**不当场编**，承诺"回去给准确数字"。核心立场：**承认边界是加分不是减分**，能当场说清自己边界的人比说"完全防住了"的人可信得多。

**可复用经验：拆问题本身也是专业动作**（承《噪音问题》）——客户的一个模糊提问（"数据噪音怎么解决"）往往**混着两个答案不同、强弱也不同的问题**。三步手法：① **先分类再选战场**（传感器/采集侧 = 我们强的那半；环境侧 = 承认它是真的但不在这里往下走，因为再下一步就是要什么信号、从哪个系统取，那是技术对接会的题）；② **把"能力问题"转成"结构性问题"**（"这不是降噪问题，是判别问题"——两种解释都是慢的单调几何变化，单通道上一个方程两个未知数，信息论上不可解，于是竞争战场从"谁的算法好"转到"谁能把两个未知数变可分离"）；③ **反问逼出具体含义**（"您说的噪音，最后落到您身上是什么？报警太多没人看，还是数据有段是空的、不动的？"——前者是误报率、我们的轴，后者是采集健康、第一件事就查这个）。**提问权即专业度。**

**可复用经验：可分离性的几种武器**（承《噪音问题》四件事）——顺序即证据强度：**多通道一致性最强**（靠物理独立性，基座漂移只动视觉通道，真实位移会在拉绳计/倾角/GNSS 同步出现，不需统计假设、标定或历史数据）；**数据纵深次之**（前提是视觉处理在自己设备上，能拿到原始图像与匹配残差，不是黑盒只吐一个读数）；**时间尺度差异再次**（支架热变形有日周期、结构蠕变没有，纯软件分析但需多天数据）；**最后是让客户做一个已知扰动实验**——把判别困境转成可执行清单，"**这条不是算力，是报告写法**"。

**长序列记忆的三种答法**：Transformer 不压缩（KV 缓存随长度涨，设备装不下）；Mamba/SSM 学一个压缩（状态恒定，黑箱）；LMU 推导一个压缩（正交多项式基，$d=4\sim8$ 系数表达长窗口，压缩这一步免训练、可解释）。

**销售与价值线（把技术翻译成客户自己能验证的话与他自己算得清的账）**：

```
进门：两条判别（PdM / SHM）+ 计量单位第一次就说对
  ↓
技术层：适应 / 运维 / 形态  →  每层一句话 + 一个"客户自己能验证"的依据
                              （他记得上次重训花了多久 / 他一定被误报坑过 / 涉密场景数据不出厂）
  ↓
价值层：三个提问，钱的数全由他回答  →  覆盖面 / 误报人工成本 / 重训往返×点位数
  ↓
兜底：答不上来就三步（不猜 → 给真实的替代物 → 记下原句、回传、真的回去查）
```

**一句话**：上半条（[销售定位-三层与可验证点.md](./销售定位-三层与可验证点.md)）立"只说他能自己验证的话"；下半条（[价值论证-三个问题用他自己的数.md](./价值论证-三个问题用他自己的数.md)）把同一原则推到钱上——**我们一个数字都不给**，既躲开报价锚点，又让客户自己说服自己。

**进门前的分类闸门**（[两条判别-PdM还是SHM.md](./两条判别-PdM还是SHM.md)）：分错了，后面每一轮都用错的模板——对着结构客户讲包络解调，对着旋转机械客户讲多通道一致性，两种错位的后果都是同一句"你整场问的是别人的问题"。判据是**看故障的物理载体，不看行业名称**（同一个业主的隧道风机是 PdM、隧道衬砌是 SHM）。同帧的第二条是**计量单位**：设备按台、结构物按座/机房/柜——**单位定错，后面每一轮都在错的尺子上还价**，且锚定不可逆（改口径 = 让客户把前面的账全部重算）。

**收尾的三步与三样**（[答不上来的时候.md](./答不上来的时候.md)）：① 不猜 → ② 给一个**真实的**替代物（"不猜"不等于"什么都不给"——给的是已知范围内的完整结构，如"软件层验证过、硬件没做"）→ ③ 记下原句、回传、**并且真的回去查**。全批材料里**只有这一条是百分之百可执行的**——前面所有话术都需要判断力，只有"这个我不确定，我不猜，回去确认后给您准确答复"不需要。带走三样：一页地图卡（三层 · PdM/SHM · 计量单位）、一页问题卡（经济三问 + 采集健康一问）、一句话（**先问采集还活着没有**——当场可执行、成本极低、两条线通用、立刻建立内行形象）。

三条贯穿纪律：① **举证责任转移给对方**（技术靠"你可以查它有没有"，商业靠"这个数只有他有"）；② **区分结构事实与价值主张**——"多套系统=多份运维"客户反驳不了（产品定义决定的既有事实），"长期总额更省"（预测）和"数据不出厂"（偏好）都会被反驳；③ **不替客户下结论**（"所以买他们的不划算"会触发反弹，改成反问"您内部是按一次性采购立项，还是按年度服务费立项？"，顺带探明预算科目）。

**贯穿全批的元纪律——内外一致**（[答不上来的时候.md](./答不上来的时候.md) 收束）：对内的未定事项清单，与对外的说法，**必须是同一份**。"今天有几个地方我说了『这个还没定』——那不是没准备好，是现在真实的状态，在客户面前也是同一个说法。"开了"内部知道没定、对外讲成已定"的口子，前面所有"你能自己验证"的设计就失去地基。而"一起把它定下来，比各自猜一个版本快得多"给出的是**效率论证而非道德论证**：各自猜 → N 个人对客户讲出 N 个规格 → 回头纠 N 次；公开说"还没定"+ 一起定 → 一次对齐。
