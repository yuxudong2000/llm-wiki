## 一、两个组件的"软件说法"

图里给出的翻译，是把机器学习概念降到工程直觉上：

### AE 自编码器 ——「一个学出来的有损压缩器」

> 压缩再还原，还原不好 = 没见过 = 异常。只对训练时见过的东西压得好。

**重构范式（reconstruction-based）**核心逻辑：

$$\min_{\theta,\phi}\ \mathbb{E}_{x\sim p_{\text{normal}}}\big\|x-D_\phi(E_\theta(x))\big\|^2$$

- 编码器 $E_\theta$：高维信号 → 低维瓶颈 $z$
- 解码器 $D_\phi$：$z$ → 重建 $\hat{x}$
- 训练目标：**只让它在正常数据上重建得好**

理论基础是**流形假设**：正常样本集中分布在一个低维流形上，网络学到的是这个流形；异常样本在流形之外，解码器没见过，自然重建得差。

⚠️ **致命弱点**：自编码器**有可能泛化得太好**——若容量足够大，异常数据在波形层面与正常数据"看起来差不多"时，会被一起重建得很好，导致漏检。这是 MemAE / Deep SVDD 等改良方法出现的直接动因（见第五节）。

AE 输出的是**重构距离（标量分数）**，不是**概率密度**——阈值靠经验拍（正常验证集 $\mu+k\sigma$），不可比、不易校准。这是后面 VAE 要补的缺口。

### LSTM ——「一个带状态的流式处理器」

> 逐个时间步喂进去，自己维护一份隐藏状态。决定记住什么、忘掉什么。

三个门控决定状态更新：

$$
\begin{aligned}
f_t &= \sigma\big(W_f[h_{t-1},x_t]+b_f\big) &&\text{遗忘门}\\
i_t &= \sigma\big(W_i[h_{t-1},x_t]+b_i\big) &&\text{输入门}\\
\tilde{C}_t &= \tanh\big(W_C[h_{t-1},x_t]+b_C\big) &&\text{候选状态}\\
C_t &= f_t\odot C_{t-1}+i_t\odot \tilde{C}_t &&\text{细胞状态（长期记忆）}\\
o_t &= \sigma\big(W_o[h_{t-1},x_t]+b_o\big) &&\text{输出门}\\
h_t &= o_t\odot\tanh(C_t) &&\text{隐藏状态（对外输出）}
\end{aligned}
$$

- $C_t$ 的**加性更新路径**是 LSTM 相对朴素 RNN 的关键：梯度沿这条路径线性回传，不经过反复矩阵乘和 tanh 压缩，缓解梯度消失、能记住更长依赖。
- **为什么振动信号适合它**：振动是天然时间序列，故障演化（退化趋势）本身是长程依赖——单个冲击没有意义，重要的是"这个模式比之前变强了多少"。
- **代价**（决定它后来被 Transformer 部分取代）：时间步**串行**、无法并行训练；隐藏状态是**固定维度瓶颈**，长序列被压进一个向量；路径长度 $O(T)$（vs 自注意力 $O(1)$）。

## 二、LSTM-AE 的机制

骨架用 LSTM，目标用重构，拼起来：

```
输入序列 x₁..x_T
   ↓  编码器 LSTM（逐步吃入，最后隐藏状态 = 瓶颈）
瓶颈 z（低维向量）
   ↓  解码器 LSTM（逐步吐出）
重建序列 x̂₁..x̂_T
   ↓  逐点比较（重要：是与输入自己比较，见第四节纠错）
重构误差 a(x) = ‖x − x̂‖²  → 超过阈值 τ 判异常
```

图里画的三条波形是这个逻辑的可视化：**见过的（健康）→ 还原得很像**（落在训练流形上）；**没见过的 → 还原得很差**（流形之外，解码器只能按学过的正常套路"猜"）。图上明确标注"波形为示意画法"——健康信号重建得像是统计意义上的，不是逐点重合。

| 工程细节 | 常见做法 |
|---|---|
| 阈值 $\tau$ | 训练结束后在**留出的健康验证集**上再跑一遍推理，取误差分布的 $\mu+k\sigma$（$k$≈3–6）或分位数 |
| 打分粒度 | 逐时间点误差 → 滑窗平滑/累积，减少误报抖动 |
| 输入形态 | 原始时域 / 频谱 / 时频图 / 阶次谱（这就是"骨架可换"的接口） |
| 归一化 | 极其关键，必须用**训练集**的统计量，否则推理时会漂 |

## 三、标注问题：一个反直觉的成本转移

> ❌ 不需要故障标注 —— 不用给它看过任何一次故障
> ✅ 需要「这一段是正常的」—— 而且要一段够长的

这类方法常被宣传为"无监督学习"，**严格术语是半监督 / 单类分类（one-class）**：

| 设定 | 训练数据 | 方法举例 |
|---|---|---|
| 有监督 | 正常 + 已标注故障 | 分类器 |
| **单类 / 半监督** | **只有正常** | **AE、LSTM-AE、OC-SVM、Deep SVDD** |
| 无监督 | 混在一起，无标签 | 聚类、隔离森林 |

"不需要故障标注"是真的，但代价转移了——从"标故障"转移到"保证正常段干净"：

> 「它不需要您标故障，但需要您先给一段够长的、您敢说是正常的数据——采出来、再有人确认它干净，通常比标注本身贵。」

为什么"确认正常"可能比"标故障"更贵：

1. **正常段要长**：要覆盖工况多样性（转速、负载、温度、季节），否则学到的"正常"是窄定义；
2. **"正常"是负向定义**：标故障是"我看到了这个异常"（正例，可穷举）；确认正常是"我检查过了这里什么都没有"（负例，无法穷举）；
3. **工业现场的"正常"往往不干净**：混着换刀、启停、维护、传感器松动、采集丢失——这些长得又很像异常；
4. **必须有领域专家参与**才能确认。

这是**重构式异常检测范式的成本中心**——不在 GPU 上，在数据准备上。

## 四、机制纠错：瓶颈与重构误差是怎么算的

> [!warning] 常见误解澄清
> 容易被误解为"拿解码后的数据与另存的一份『正常数据模板』做对比"。**实际不是**——是拿解码输出**与这次的输入本身**做对比。

### 4.1 训练 vs 推理，两个阶段做的事不同

**训练阶段**（用大量正常数据，优化的是网络权重，不是"生成一个瓶颈"）：

- 收集很多段正常序列（覆盖各种工况，不是一段）；
- 反复喂给"编码器→瓶颈→解码器"，用重构误差（输入 vs 该样本自己的重建输出）当损失函数，反向传播；
- 优化目标是**网络权重**（编码器/解码器里所有 LSTM 的门控参数）；
- **瓶颈不是训练时存下来的一个固定值**——瓶颈是网络结构里的一层。训练结束固化下来的是权重，不是某个具体瓶颈向量。

**推理阶段**（每来一条新序列，都现算出一个"属于它自己"的瓶颈）：

```
新采集数据 x（可能正常也可能异常，训练时没直接见过这一条）
   ↓  编码器（用训练好的权重）
瓶颈 z（这一次输入专属，每次都不同）
   ↓  解码器（同样用训练好的权重）
重建输出 x̂
   ↓
误差 = distance(x, x̂)   ← 是 x 自己，不是另一份正常数据
   ↓
误差 > 阈值 τ → 判异常；误差 ≤ τ → 判正常
```

**为什么"跟自己比"就能测出异常**：权重只在正常数据上训练，对"正常模式"擅长压缩还原；碰到没见过的异常模式，权重不知道怎么编码，解码器只能按学过的"正常套路"硬凑输出，凑出来的和真实（异常的）输入自然差得远。**误差大小本身就是"这段数据离训练集里正常模式有多远"的度量**，不需要真去比对一份"标准正常数据"。

阈值 $\tau$ 的来源：训练完之后在留出的健康验证集上跑一遍推理，算这批数据各自的重构误差分布，取 $\mu+k\sigma$ 或分位数——这一步间接用到了"正常数据"，但用途是**校准误差的正常波动范围**，不是拿去跟新数据的解码结果直接比对。

### 4.2 瓶颈到底是什么

**字面**：网络中间被"挤窄"的地方，一个沙漏形结构：

```
输入 x (维度 D) → 编码器(逐层降维) → 瓶颈 z (维度 d，d≪D) → 解码器(逐层升维) → 输出 x̂ (维度 D)
```

对 LSTM-AE：编码器 LSTM 吃完整段序列后，**最后一步的隐藏状态** $h_T$（定长向量）就是瓶颈：

$$z=h_T=\text{Encoder}_{\text{LSTM}}(x_1,\dots,x_T)\in\mathbb{R}^d,\qquad d\ll T\times m$$

**瓶颈为什么必须窄——这是方法能 work 的前提**：若瓶颈维度和输入一样大，网络能学到恒等映射 $z=x,\ \hat x=x$，任何输入（正常/异常）都重构误差为 0，**毫无诊断能力**。瓶颈窄逼着网络只能保留"最重要、最普遍"（相对训练集而言）的信息，丢弃细枝末节：

- 正常数据的规律模式，恰好是网络学会保留的部分 → 编码有效、解码凑得回来 → **误差小**
- 异常数据的新模式（故障冲击），训练时从没学过要保留 → 瓶颈装不下、被当作"不重要细节"丢掉 → 解码器只能按正常套路"猜" → **误差大**

**类比**：读一段文字后闭卷复述。文字短就一字不差记住再念（= 瓶颈=输入，没有压缩，不叫理解）；文字长只能记住一个**摘要**（= 瓶颈），复述时靠摘要重新组织；原文是熟悉套路（正常模式）摘要抓得准；混进一句完全没见过的怪话（异常），摘要机制不知道要保留它，复述时会被"编"成别的东西，跟原文差得远。

**三个常见误解**：

1. 瓶颈**不是**训练时"存下来"的一个固定值——它是网络结构里的一层，每条新输入都现算出属于它自己的瓶颈；固化下来的是权重。
2. 瓶颈宽窄是需要调的超参数，不是越窄越好：太窄 → 正常数据自己都重建不好，误报率高；太宽 → 退化成近似恒等映射，异常也重建得好，漏报。这也是"换季节/工况往往要重新训"的原因之一——正常模式的多样性变了，原来的宽度不够用。
3. LSTM-AE 的瓶颈额外坍缩了**时间维度**——整段序列被压成一个时刻的状态，隐含保留"随时间演变的规律"，这正是为什么故障（打破时间规律性的突发冲击）特别容易在这种结构里"露馅"。

## 五、成本长在三个地方（运维视角）

> ① 要 GPU 训练
> ② 换一个条件、换一个季节 → 往往要重新训
> ③ 训练是离线的 —— 现场变了，收数据回来、重训、再发下去

**① GPU 训练**：一次性投入，本身不算大事。

**② 域漂移（domain shift）/ 概念漂移（concept drift）**：

- **概念漂移**：设备本身在变——磨损、更换零件、大修，"正常"的定义变了；
- **域漂移**：工况在变——季节（温度影响润滑油黏度、结构共振频率）、负载、转速、上下游工艺。

AE 学到的流形是训练时那一刻的切片。季节一变，信号统计特性整体偏移，原本"正常流形"不再覆盖真正正常的数据 → **误报率飙升**（典型失败模式：把没见过但正常的模式判成异常）。

**③ 离线闭环延迟**：

```
现场 → 采数据 → 传回 → 重训 → 验证 → 部署 → 现场
              └────────── 可能以周/月计 ──────────┘
```

闭环转完之前，模型用的是过期的正常定义——持续误报（导致**告警疲劳**，运维最后把告警关掉，这是最大的失败）或漏报。

**差异化主张**：不比精度，差别在"它变了要重训 / 在线上跟住"，且**随点位放大**（一个厂 5000 个测点 = 5000 个模型 = 5000 份正常数据 = 5000 次重训，离线路线边际成本几乎不降，在线跟踪路线更接近固定开销）。

> [!note] 需要留意的修辞
> 图上写「本图不含任何精度对比 —— 不在精度这一维上竞争」。这是有意识的话术选择：承认精度不是战场，把战场定义在运维成本上。这既是立场声明也是风险点——若对手精度优势足以覆盖运维成本，此论证会失效。当作内部材料理解，不要当成已证实的技术结论。

## 六、骨架 × 目标：二维分类法（最有复用价值的部分）

> LSTM-AE = 用循环骨架做序列重构 —— **两个维度各自可换**：
> 换骨架 → Conv-AE（卷积，跑频谱图）、Transformer-AE；换目标 → VAE（给概率不给距离）。
> 他们报出任何一个新名字，先问这两句：**骨架是什么？目标是什么？** —— 十有八九落在这张表里。

### 维度 A：骨架（输入怎么被处理）

| 骨架 | 处理对象 | 典型场景 |
|---|---|---|
| 全连接 AE | 定长向量（统计特征/FFT 谱） | 最简单基线 |
| **LSTM/GRU-AE** | 原始时域序列 | 时序依赖、退化趋势 |
| 1D-CNN-AE | 原始时域一维卷积 | 局部冲击模式、可并行 |
| **2D-CNN-AE** | **时频图（STFT/CWT/阶次谱）** | 工业界最常用，图像化后借 CNN 红利 |
| Transformer-AE | 长序列，自注意力 | 长程依赖、可并行训练 |
| GNN-AE | 多测点传感器图 | 测点间关联建模 |
| 混合（CNN+LSTM） | 先卷积提特征再循环建模 | 常见工程折中 |

### 维度 B：目标（拿什么度量"还原得好"）

| 目标 | 核心变化 | 代价/收益 |
|---|---|---|
| **AE** | $\lVert x-\hat x\rVert^2$ | 简单；输出**距离**不是概率；可能泛化过度 |
| **DAE** 去噪自编码器 | 输入加噪，重建干净版 | 学到更鲁棒表征；需设计噪声 |
| **VAE** 变分自编码器 | 学 $p(z)$ 分布，损失=重构+KL | **给概率密度**，可校准；可能给异常高似然、后验坍缩 |
| **AAE** 对抗自编码器 | 判别器匹配先验分布 | 训练不稳 |
| **MemAE** 记忆增强 | 加记忆库约束编码 | **直接针对"重建得太好"** |
| **Deep SVDD** | 不重构，把正常样本压进超球 | 单类分类，目标根本不是重构 |
| 马氏距离 AE | 协方差加权残差 | 考虑特征相关性 |

**VAE 为什么"给概率不给距离"**：训练目标是最大化证据下界（ELBO）：

$$\log p(x)\ \ge\ \mathbb{E}_{q(z|x)}\big[\log p(x|z)\big]\ -\ D_{KL}\big(q(z|x)\,\|\,p(z)\big)$$

编码器输出 $\mu,\sigma$ 而非确定向量，异常分数可取 $-\text{ELBO}$ 或重构概率。好处：有概率语义、阈值可解释、可做不确定性量化；坑：**VAE 可能给异常数据比正常数据更高的似然**——重构项和 KL 项在异常点上可能同向"作弊"。

### 快速定位表

| 听到的名字 | 骨架 | 目标 |
|---|---|---|
| LSTM-AE | LSTM | 重构 L2 |
| Conv-AE / CAE | 2D CNN | 重构 L2 |
| Transformer-AE / TranAD | Transformer | 重构 + 对抗 |
| USAD | 共享编码器+双解码器 | 对抗训练放大异常 |
| DAGMM | 全连接 AE + GMM | 重构 + 密度估计 |
| MSCRED | CNN + LSTM | 多尺度卷积重构 |
| MemAE | 全连接/CNN + 记忆 | 重构 + 记忆约束 |
| Deep SVDD | 任意 | **超球紧凑性（非重构）** |

唯一"落不进表"的是 Deep SVDD 这类——它连"目标=重构"这个前提都换了，所以"十有八九"这个措辞是准确的，留了余地。

## 七、与前端三件套的对照

| | 三件套（前端） | LSTM-AE 类深度学习路线 |
|---|---|---|
| **定位** | 前端信号调理 + 后端在线跟踪 | 端到端离线重构检测 |
| **依赖先验** | 强（几何公式、共振带、阶次） | 弱（让网络自己学） |
| **故障定位** | 明确（BPFO 等物理坐标） | 弱（只有异常分数，不回答"坏在哪"） |
| **变工况** | 角域重采样归一化，无需重训 | 域漂移 → 往往要重训 |
| **数据需求** | 少量正常 + 物理参数 | 长段确认干净的正常数据 |
| **成本结构** | 固定开销为主 | 随点位线性放大 |

## 八、知识点清单

**模型层**
1. 自编码器：编码-瓶颈-解码、重构损失、流形假设
2. 重构式异常检测的成立条件与**泛化过度**问题
3. LSTM：三门一状态、细胞状态的加性路径、梯度消失的缓解
4. RNN 串行瓶颈 vs Transformer 注意力并行
5. LSTM-AE 组合方式：序列 → 瓶颈向量 → 序列
6. 阈值设定：健康验证集 $\mu+k\sigma$ 或分位数
7. VAE：ELBO、KL 项、$\mu/\sigma$ 编码、概率 vs 距离的本质差异
8. 变体族：DAE / MemAE / AAE / Deep SVDD / DAGMM / USAD / TranAD
9. **瓶颈的本质**：信息压缩约束，是方法生效的前提而非缺陷；宽窄是超参数；LSTM-AE 额外坍缩时间维度
10. **重构误差怎么算**：解码输出 vs 输入自身，不是 vs 存好的正常模板；权重训练与瓶颈推理是两个不同阶段

**数据层**
11. "无监督"的误称——实为**单类/半监督**
12. 正常段数据获取成本 > 故障标注成本这一反直觉结论
13. 长正常段需覆盖工况多样性；"正常"是负向定义、不可穷举
14. 工业现场"正常"数据通常不干净（启停/维护/采集异常）

**运维层**
15. 概念漂移 vs 域漂移的区分
16. 离线重训闭环的延迟与冻结期风险
17. 告警疲劳——误报的隐性成本高于漏报
18. 成本随点位线性放大 vs 固定开销的路线差异
