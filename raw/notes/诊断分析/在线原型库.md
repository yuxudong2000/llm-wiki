# 在线原型库：我们出货的东西实际是什么

> 来源：一张产品定义示意图（原始图片未归档，仅整理文字内容）
> 整理时间：2026-09-23

> [!warning] 保密标记
> 原图页脚标注「[保密级] 仅限国内团队内部，不得外发」。与前几张竞品路线图属同一份材料（本文为「③」帧，前两帧为竞品路线 A / B）。**本仓库会 push 到 git remote**，入库前需确认可达范围或做去标识化处理。

**一句话**：这一帧讲的是自研线**实际交付给客户的东西长什么样**——不是"一个训练好的深度模型"，而是**一个在线维护的向量索引 + 最近邻匹配**：一帧信号进来，跟库里 K 条"典型状态"原型比余弦相似度取最高的那条；够像就输出该原型携带的语义标签、并让这条原型朝它挪一小步；都不够像就报「**没见过**」。

**顶部导语（全帧的重量所在）**：

> 这一帧是全场最需要说准的。**说错的代价不是尴尬，是客户按错的东西去选硬件。**

这句把"表述准确性"与商业后果直接挂钩——若客户以为系统能力超出实际（以为它会自动发现新故障类型、会持续无限制自学习），他就会按错误的能力假设去规划采样率、点位规模、验收标准，最终是一笔错误的硬件投入。这是本系列一贯纪律线的延续（"没测过就说没测过""不比精度"），只是这次的代价从"失信"升级为"误导采购"。

## 一、三步流水线

### ① 一帧信号进来 → 输入向量

> 这一段信号的**频谱 / 特征**

关键点：**入口不是原始波形，是已算好的特征向量**。前端特征工程（频谱、阶次谱、统计量）仍是能力上限的决定因素——这一帧讲的是**决策层**，不是感知层。

### ② 跟库里每条比相似度 → 原型库（K 条「典型状态」）

库里的条目是**带语义标签的原型**：

| 原型 | 标签 |
|---|---|
| 原型 1 | 正常 · 低负载 |
| 原型 2 | 正常 · 高负载 |
| 原型 3 | 已知异常形态 |
| … | 共 K 条 |

注意"正常"被拆成**低负载 / 高负载等多条**——这正是前面几帧反复强调的"正常段必须覆盖工况多样性"的工程落地：不是一条笼统的"正常"，而是按工况分多条，否则窄定义会立刻退化成误报。

判定规则图里写明：**取相似度最高的那一条（余弦 · argmax）**。展开见第二节。

### ③ 两条出路

两条路给出的**是完全不同性质的东西**——这是全帧的语义核心。

#### 出路 A（绿）：匹配上了（够像）

> → 输出当前状态
> → **这条原型朝它挪一小步**（跟住缓慢变化）

两件事同时发生：

1. **输出带语义的状态**：因为原型自带标签（"正常·低负载"、"已知异常形态"），匹配成功即直接给出可解释结论。这是相对"只输出异常分数、不回答坏在哪"的重构式深度学习路线的实打实优势。
2. **在线微调**——前几帧一直铺垫的"线会自己挪"落到具体机制上：

$$p_{i^\*} \leftarrow p_{i^\*} + \eta\,(x - p_{i^\*}),\qquad \eta \ll 1$$

只有**胜出的那条原型**被更新（竞争学习 / LVQ 式规则），$\eta$ 小所以是"挪一小步"而非跳变。这就是"跟住缓慢变化"——不是重训模型，是原型位置的**指数移动平均**。

> 这是与前两帧的关键分野：竞品路线 A 靠**离线重训**（周/月级延迟）、竞品路线 B 靠**人工每季度重画控制限**，自研线靠**原型小步在线微调**——不需重训、不需人工重标，代价是只能跟"缓慢"变化。

#### 出路 B（红）：都不够像 → 报「没见过」

> **客户的所有可行动作都建立在这一位上**

**这是全帧最需要说准、也最容易被讲错的地方**：

> 它报的是「**没见过**」，不是「**故障**」。

| | 报「故障」 | 报「没见过」（实际设计） |
|---|---|---|
| 语义 | 已判定你知道这是什么问题 | 只判定"我不认识这个模式" |
| 需要的能力 | 完整故障分类能力 | 只需"匹配失败"这一元判断 |
| 是否可能误伤 | 是（新工况也会被判故障） | 否（诚实承认"不知道"） |
| 客户动作 | 直接检修 | 人工核查 → 再决定动作 |

"没见过"是一个**带拒识（reject option）**的判别系统输出的兜底语义——它规避了"把没见过但正常的新工况误判成故障"这个典型失败模式（域漂移导致误报率飙升）。代价是它**不回答"这是什么问题"**，需人接手。图里"客户的所有可行动作都建立在这一位上"，即是说：**系统的实用价值边界由这条「没见过」判断的质量决定**。

图上还有一条**虚线回流**（从出路区域绕回原型库），标注：

> **缓慢更新（受预算上限 + 停学门约束）**

需说明一处边界：**"不新增类别"意味着"没见过"这一路不会往库里加新原型**——miss 只负责"报"，不负责"学"。所以虚线更应理解为对**更新机制整体**的标注（其具体实例就是出路 A 那句"原型朝它挪一小步"），而非"miss 也会触发改写"。（原图未明确标注虚线起止，此处按语义推断。）

## 二、"余弦 · argmax"到底在判什么

这句话里藏着**两件事**，图面只写了其中一件——这是理解这一格的第一道坎。

| 步骤 | 数学操作 | 回答的问题 |
|---|---|---|
| **argmax** | $i^\*=\arg\max_i \cos(x,p_i)$ | **哪一个**最像？（排序，选冠军） |
| **阈值** | $\max_i\cos(x,p_i)\ \ge\ \tau\ ?$ | **够不够**像？（决定走绿路还是红路） |

**argmax 本身永远不会返回"没有"**——只要库里有 K≥1 条原型，它必定挑出一条冠军，哪怕冠军相似度只有 0.1。所以"两条出路"这个分支**不可能由 argmax 单独完成**，必须再配一个阈值 $\tau$。图上 ② 只画了 argmax、③ 画了分支，中间那步"跟 $\tau$ 比"被省略了——但它是「报没见过」这条路唯一的开关。

> **argmax 负责"最像谁"，阈值负责"像不像"。**

### 2.1 余弦相似度是什么

$$\cos(x,p)=\frac{\langle x,p\rangle}{\lVert x\rVert\,\lVert p\rVert}=\frac{\sum_j x_j p_j}{\sqrt{\sum_j x_j^2}\sqrt{\sum_j p_j^2}}$$

几何含义是两个向量**夹角的余弦**：$=1$ 方向完全一致（长度可不同）；$=0$ 正交、毫无共同成分；对频谱这类非负向量取值落在 $[0,1]$。

**核心性质：只看方向，不看长度。** $x$ 整体乘 2，余弦不变（分母 $\lVert x\rVert$ 同步放大被约掉）。

**数值例子**：取三维特征 $x=[0.6,0.8,0]$，库中三条原型：

| 原型 | 向量 | $\cos(x,p_i)$ |
|---|---|---|
| $p_1$ | $[0.8,0.6,0]$ | $0.48+0.48=0.96$ |
| $p_2$ | $[0,0,1]$ | $0$ |
| $p_3$ | $[0.1,0.2,0.97]$ | $0.06+0.16=0.22$ |

$\arg\max = p_1$（0.96）。若 $\tau=0.9$ → 匹配上，走绿路，输出 $p_1$ 的标签，并把 $p_1$ 朝 $x$ 挪一小步。换成 $x'=5x$，三个余弦值**完全不变**——这就是"方向不变、幅值无关"。

### 2.2 为什么用它，而不是欧氏距离

**直接原因：振动特征的幅值极不可靠。** 同一设备同一状态的频谱，整体幅值会被一堆与故障无关的因素改变：负载/转速（图中原型 1、2 即按低/高负载分开）、传感器灵敏度与安装扭矩、采集增益与线缆。若直接算 $\lVert x-p\rVert$，"形状完全一致但整体高 20%"会被判为**很远**。余弦把这些乘性因素约掉，只留"哪些频率成分相对更强"这个**形状**信息——恰是判别状态的核心。

**与前一帧的呼应（同一片点云，换判别几何）**：若先做 L2 归一化 $\hat x=x/\lVert x\rVert$，则

$$\lVert \hat{x}-\hat{p}\rVert^2=2-2\cos(x,p)$$

**归一化后的欧氏距离与余弦严格单调反向**：$\arg\max\cos\equiv\arg\min\lVert\cdot\rVert$。这正是 [竞品路线B-经典统计五件套.md](./竞品路线B-经典统计五件套.md) 里"同一片数据、只换判别几何"在本帧的翻版——马氏距离是在**椭圆化**空间量距离，余弦是在**单位球面**上量距离。

**代价：丢掉幅值。** 振动诊断里**幅值恰恰是严重程度的主要指标**（同一根 BPFO 谱线从 0.01 涨到 0.1，即从早期到严重），余弦对此**完全无感**。工程上标准解法是两路并行：

| 判断 | 用什么 | 回答 |
|---|---|---|
| 形态属于哪种状态 | **余弦相似度**（本帧） | "像正常·低负载，还是像已知异常形态 X" |
| 严重到什么程度 | 另一路幅值指标（总 RMS、特征频带能量、峭度） | "比上次严重了多少" |

推论：**传感器增益衰减这类故障，纯余弦方案检不出来**（只改幅值不改形状）；反过来，换传感器、改量程不必重新校准阈值。

### 2.3 工程细节与坑

**① 余弦 vs 相关系数（要不要去均值）**：余弦**不去均值**。若频谱含巨大直流/低频分量，它会主导内积，余弦实质变成"比谁低频分量大"，故障特征被淹没。两种常见处理：先去直流再算（等价于皮尔逊相关系数 $r=\frac{\langle x-\bar x,\,p-\bar p\rangle}{\lVert x-\bar x\rVert\lVert p-\bar p\rVert}$），或按频带裁剪/加权（只保留共振带等 ROI）。后者更常见，也解释了入口为何写"**频谱 / 特征**"——特征怎么构造，直接决定余弦在比什么。

**② 高维余弦集中现象（cosine concentration）**：维度越高，随机向量越趋于正交，余弦值全挤在 0 附近、彼此差别极小。后果：冠军与亚军只差千分之几，"取最像的一条"的**信心很脆**；阈值 $\tau$ 的绝对数值失去直觉，**不可跨特征方案移植**。

**③ 阈值怎么定，以及方向反了**：与重构式异常检测同一套路，但方向相反——

| | 重构误差 | 余弦相似度 |
|---|---|---|
| 异常方向 | 分数**越大**越异常 | 相似度**越小**越异常 |
| 阈值取法 | 正常验证集误差的 $\mu+k\sigma$（上分位） | 正常验证集「最高相似度」的**下分位数** |

步骤：拿一批确认干净的正常数据，逐条跑"算 K 个余弦 → 取最大"，得一组"正常样本的最近邻相似度"分布，取低分位作 $\tau$；低于 $\tau$ 即"连最像的原型都够不着"→ 报没见过。

**耦合提醒**：$\tau$ 与 $K$ 强相关——库越大，"撞上某条原型"的机会越多，最高相似度被整体抬高，**扩容后不能沿用旧阈值**。对应本帧语境：装机时重新定义类别（K 变了）之后必须重新校准 $\tau$。

**④ 更新规则与匹配规则不一致（藏得较深）**：匹配用**余弦**（单位球面上的角度），但"朝它挪一小步"在数学上是**欧氏空间的直线插值** $p\leftarrow p+\eta(x-p)$。若匹配依据是角度，更新理想上也应在球面上进行（归一化后插值 / 球面线性插值），否则原型**模长**会随更新漂移，而模长又会被下一次余弦的分母吃掉——长期可能出现"原型越挪越长/越短"的隐性漂移。工程上通常靠**每步更新后重新归一化**堵这个口子，代价很小但必须做。

### 2.4 它在机器学习里的原身

这套「K 个原型 + 最近邻分配 + 胜者小步更新」，精确对应**在线矢量量化 / 在线 LVQ（Learning Vector Quantization）**，也等价于 $\eta$ 极小的**在线 k-means**：

| 本帧的说法 | 对应机制 |
|---|---|
| 原型库（K 条典型状态） | **码本 / codebook**（k-means 簇中心） |
| 余弦 argmax 取最像的一条 | **最近邻编码**（分配步 argmin） |
| 这条原型朝它挪一小步 | **胜者更新**（中心更新步，$\eta$ 即学习率） |
| 够不够像（阈值 $\tau$） | **编码残差门限**（量化误差过大 → 码本无合适码字） |
| 报「没见过」 | **量化外样本 / miss**，正对上左下框"查不中就返回 miss" |

所以这套东西不是新鲜发明，而是**五十年历史的经典算法（矢量量化）**加上三个工程约束后的产品化形态。这也让"不需要 GPU、不需要训练"变得可解释：**码本不是训练出来的，是初始化 + 在线增量更新出来的**。

三家分野也因此清晰：

- 竞品 A（深度学习）：一次离线训练出**全局函数**；
- 竞品 B（经典统计）：一次统计算出**固定边界**；
- **本帧（原型库）：从不做一次性拟合，只有持续的小步局部修正。**

代价同样清楚：这套机制**天然只能微调、不能长出新东西**——这就是"不新增类别"在算法层面的根源，不是产品经理设的限制，而是**算法本身的性质**。

## 三、「受约束的在线学习」三条限定

右下框是全帧**最需要被准确理解的技术立场**：

> 这就是**「受约束的在线学习」**
> 它**确实在从现场数据改参数** —— 三条限定：
> **有预算上限 · 有停学门 · 不新增类别（新类别在装机时定）**

**前提承认——"它确实在从现场数据改参数"**：不回避、不含糊，这套系统**不是**静态规则手册，参数（原型位置）确实会被现场数据改变。这是对"你在线上自己改模型"这类质疑的正面承认。承认很关键：若遮遮掩掩，一旦被发现，信任整体崩塌的代价更大。

**限定一：有预算上限**——更新幅度、频次、总量受控。工程含义：防止原型被少量异常样本"拖跑"（若更新无界，连续几次罕见但有冲击性的正常事件就能把"正常·低负载"原型拽向异常方向，之后系统性误报）；同时提供**可承诺、可计量的运维开销**语义。

**限定二：有停学门**——可以**主动关掉学习**。工程含义：**可复现/可审计**（需要时冻结，让行为确定）；**验证期不被污染**（客户验收、比对测试期间冻结，避免"边测边学"导致结论不可信）；**问题排查**（误报时先停学，排除"是不是自己学歪了"）。这把"自适应"从不可控黑箱变成**运维手里有开关的能力**，本身是产品化成熟的标志。

**限定三：不新增类别（新类别在装机时定）**——类别体系固定，装机（commissioning）时确定，运行期只允许原型位置微调，**不允许长出新的类别**。直接推论：

- **没有开集识别（open-set recognition）能力**——系统**不可能自动发现一种从未定义过的新故障类型**；
- 积极面：库规模**有界**（K 条，不增长），资源占用确定——恰好是前面批评 Transformer"KV 缓存 $O(T)$ 不设上限"的镜像，自研线从原型库这一层就锁死"大小恒定"；
- 诚实面：现场出现"新故障形态"时**必须重新装机/重新定义类别**，不能指望系统自己长出来。这正是顶部警告"客户按错的东西去选硬件"最可能踩的点。

> [!warning] 这一帧的正确说法
> **应当说**：它是一个「匹配已知典型状态、遇不认识的模式就报『没见过』、并按受约束的方式缓慢跟随基线漂移」的在线原型库。
> **不应当说**：它会自动发现新故障类型（受"不新增类别"限制）/ 它会持续自动学习（受预算与停学门约束）/ 它会告诉你"坏在哪"（只报"没见过"）。

## 四、左下框：软件的说法

> **一个在线维护的向量索引 + 最近邻匹配。**
> 索引里的条目会随流量缓慢自我更新；**查不中就返回 miss**。

| 软件概念 | 对应本系统 |
|---|---|
| 向量索引（vector index） | 原型库（K 条特征向量） |
| 最近邻匹配 | 余弦相似度 + argmax |
| 索引条目缓慢自我更新 | 原型位置的在线微调 |
| **查不中就返回 miss** | 相似度全低于阈值 → 报「没见过」 |

"查不中就返回 miss"这个类比特别准——它把"没见过"从"检测失败"重新框定为**一次正常的未命中（index miss）**：miss 不是系统故障，是系统的正常输出之一。同时"在线维护的向量索引"让整套东西听起来完全工程可实现（不需 GPU、不需训练），而非研究概念。

## 五、方法定位与三方对比

把三步拼起来，这套东西在方法论上的准确名字是：

> **带拒识的判别式原型匹配（prototype-based / nearest-neighbor classification with reject option）+ 受约束的原型在线自适应**

| | 竞品路线 A（深度学习） | 竞品路线 B（经典统计） | **本帧（自研线）** |
|---|---|---|---|
| 决策依据 | 重建误差 $\lVert x-\hat x\rVert$ | 距离 / 残差 / 边界 / 树路径 | **到最近原型的余弦相似度** |
| 输出 | 异常分数（无语义） | 越限/未越限（弱语义） | **带标签的状态 +「没见过」** |
| 适应变化 | 离线重训 | 人工重画控制限 | **原型小步微调（预算上限 + 停学门）** |
| 库/状态规模 | 参数固定，数据流无界 | 固定 | **K 条，恒定不增长** |
| 新故障类型 | 需重训 | 需重新标定 | **需重新装机（不支持开集）** |
| 资源 | 需 GPU 训练 | 极低 | 极低（无需训练、无需 GPU） |

## 六、这套设计暴露的局限

1. **原型污染**：更新若不禁入 miss 样本（"不新增类别"已隐含此意），就不会把异常学成正常；若实现上误让 miss 参与更新，灾难性后果是异常被"正常化"——这解释了为什么"不新增类别"同时是**能力限制也是安全设计**。
2. **类别不平衡导致漂移不均**：长期主导工况的原型被频繁更新、贴合很好；稀有工况的原型几乎不动、逐渐失配。多原型设计缓解但不消除。
3. **余弦阈值的不可校准性**：相似度阈值无概率语义，"够不够像"定在哪是工程经验值，跨设备/跨场景不能直接移植；且与 $K$ 强耦合。
4. **维度灾难 / 余弦集中**：K 条原型在高维空间覆盖能力有限，维度越高邻近性区分度越差——特征维度选择本身是关键工程决策。
5. **幅值信息缺失**：纯余弦对"严重程度"无感，必须外挂幅值指标。
6. **只跟"缓慢"漂移的边界**：与前面几帧一致，快速工况跳变不在射程内（换工况仍须重新装机）。
7. **结构性盲区（承下一篇）**：见 [应答设计-故障会不会被学进去.md](./应答设计-故障会不会被学进去.md)——"容忍缓慢漂移"与"检出缓发早期故障"在数学形态上是同一个现象，靠调参数只能做权衡，无法彻底分开。

> [!note] 后续补完（命名与架构）
> [应答设计-故障会不会被学进去.md](./应答设计-故障会不会被学进去.md) 揭示了本篇未交代的两点：① 架构实为**两级**（K 槽工作记忆 + N 条持久库），**该篇的 K 与本篇的 K 指代不同**（本篇 K = 原型条数，该篇 K = 工作记忆槽数、N = 持久库条数），对照时勿混；② N 到容量上限后超限输入会被**静默并入最近一条（返回值同形）**，且"加大 N 只能推后、不能消除"。

## 七、知识点清单

**机制层**
1. 在线原型库三步：输入特征向量 → 余弦 argmax 匹配 K 条原型 → 匹配上输出标签并微调 / 不够像报「没见过」
2. **余弦相似度** $\cos(x,p)=\frac{\langle x,p\rangle}{\lVert x\rVert\lVert p\rVert}$：只看方向不看长度，对幅值乘性因素免疫
3. **argmax 与阈值是两个操作**：argmax 选冠军（永不返回"没有"），阈值 $\tau$ 决定"够不够像"——后者是「没见过」的唯一开关
4. 归一化后欧氏距离与余弦严格单调反向（$=2-2\cos$）：又一种"只换判别几何"
5. 余弦不去均值，必要时先去直流（≈皮尔逊相关系数）或按频带加权裁剪
6. **胜者更新规则** $p\leftarrow p+\eta(x-p)$：竞争学习 / LVQ / 在线 k-means，只更新冠军原型
7. 匹配用角度、更新用直线插值的**不一致**——需每步重新归一化防模长漂移
8. 阈值取正常验证集"最高相似度"的**低分位**（与重构误差取高分位方向相反），且与 $K$ 耦合
9. **余弦集中现象**：高维下相似度趋同，区分度下降

**方法定位层**
10. 本系统 = **带拒识的原型匹配（prototype + reject option）+ 受约束在线自适应**
11. 其算法原身是**矢量量化 / LVQ / 在线 k-means**——经典算法 + 工程约束的产品化
12. 「不需要训练」的可解释性：码本由初始化 + 在线增量更新得到，非一次性拟合

**产品/边界层**
13. 「没见过」≠「故障」：带拒识的输出语义，规避新工况误判，但需人工接手
14. **受约束的在线学习三条限定**：预算上限、停学门、不新增类别
15. 不新增类别 ⇒ **无开集识别能力** + 库规模有界（资源确定）
16. 停学门的三个用途：可复现/可审计、验证期不被污染、问题排查隔离变量
17. 表述纪律：说错能力边界 → 客户按错误假设选硬件
