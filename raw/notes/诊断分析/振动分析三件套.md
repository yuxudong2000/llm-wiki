# 传统振动分析三件套

> 来源：与 AI 的对话整理（围绕 `振动信号诊断四步流水线.md` 所载流程图的展开）
> 整理时间：2026-09-23

"三件套"= 流程图的 **①②③**：**采集原始波形 → 算特征频率 → 包络解调**。它们是**基于物理先验、无需训练数据的信号调理流水线**，回答"信号里有没有故障成分、在哪个频率上、有多强"。第④步（阶次跟踪）不在三件套内，它是给三件套打的补丁。

---

## 一、第一件：原始振动波形（采集）

决定后面所有分析的上限。信号没采对，后面全是空转。

### 传感器选型

| 类型 | 测什么 | 适用 | 关键限制 |
|---|---|---|---|
| 压电加速度计 | 壳体绝对加速度 | 滚动轴承、齿轮箱、通用 | 需 IEPE/ICP 恒流源；对低频和高温敏感 |
| 速度传感器 | 壳体绝对速度 | 中低频（10–1000 Hz）、老式测振仪 | 体积大、有运动部件 |
| 电涡流位移探头 | 轴相对轴承座的**位移** | 滑动轴承（汽轮机、压缩机） | 非接触；只测相对量，不做绝对振动 |
| 声发射 AE | 100 kHz–1 MHz 弹性波 | 极早期、低速轴承 | 成本高、衰减快、易受工艺噪声干扰 |

### 采集链上的死穴

- **采样率**：工程取 $f_s \ge 2.56 f_{max}$（抗混叠滤波器过渡带留 28% 余量）。要抓共振带就得 $f_s$ 到 10–50 kHz。
- **抗混叠滤波**：必须在 A/D **之前**。混叠一旦发生，高频折叠到低频后**无法事后分离**，会伪造出根本不存在的特征频率。
- **安装方式**（决定高频响应上限）：钢螺栓 ≥10 kHz > 胶粘 5–10 kHz > 磁座 ≈2 kHz > 手持探针（最差）。**测滚动轴承故障却用磁座 ≈ 把共振带直接掐掉。**
- **单向 vs 三向**：轴向分量对齿轮箱、对中问题很关键。

### 量纲选择——"三参数各管一段"

| 参数 | 敏感频段 | 典型用途 |
|---|---|---|
| 位移 µm | < 10 Hz | 轴系摆动、油膜涡动、转子偏心 |
| 速度 mm/s(RMS) | 10 Hz–1 kHz | **整机振动烈度评价**（ISO 10816 / 20816） |
| 加速度 m/s² | > 1 kHz | 轴承、齿轮、冲击类故障 |

⚠️ 这是**同一信号的微分/积分关系**（$v=\int a\,dt$，$x=\iint a\,dt$），不是三种独立测量。选哪个 = 想放大哪一段频段的信噪比。

### 时域直读指标

RMS（能量）、峰值/峰峰值、**波峰因数 CF = 峰值/RMS**、**峭度 Kurtosis**（对冲击敏感、对早期故障灵）、裕度因子。无需任何模型，常在包络分析前做第一轮筛查。

## 二、第二件：特征频率（把频谱上的线翻译成部件）

输出是一张**"序数表"**，让频谱上每根线都对应到一个具体机械部件。

### 通用转频相关

| 特征 | 常见成因 |
|---|---|
| 1× $f_r$ | 不平衡、偏心、电机转差 |
| 2× $f_r$（常比 1× 突出） | 对中不良、轴弯曲、机械松动 |
| 0.4–0.5× $f_r$ | 油膜涡动 / 半速涡动（滑动轴承） |
| 大量 $k f_r$ 谐波 + 亚谐波 | 机械松动（非线性特征） |

### 滚动轴承核心公式

$n$ 滚珠数、$d$ 滚珠直径、$D$ 节径、$\alpha$ 接触角：

$$f_{BPFO}=\frac{n}{2}f_r\Big(1-\frac{d}{D}\cos\alpha\Big),\qquad f_{BPFI}=\frac{n}{2}f_r\Big(1+\frac{d}{D}\cos\alpha\Big)$$

$$f_{BSF}=\frac{D}{2d}f_r\Big[1-\Big(\frac{d}{D}\cos\alpha\Big)^2\Big],\qquad f_{FTF}=\frac{1}{2}f_r\Big(1-\frac{d}{D}\cos\alpha\Big)$$

**判读口诀**：

- **外圈**：$k f_{BPFO}$ 谐波族，峰锐利、能到很高阶（外圈固定，冲击源不转）
- **内圈**：$k f_{BPFI}$ 谐波族 **且两侧带 $f_r$ 间隔边带**（内圈随轴转，进出于承载区 → 被转频调制），到 3–4 阶就开始糊
- **滚动体**：$k f_{BSF}$，常伴 $f_{FTF}$ 边带（自转+公转）
- **保持架**：$f_{FTF}$ 及谐波，能量通常很低，易被埋

⚠️ 实际 BPFO 与公式值常有 **1–2% 偏差**（滚动体滑移、接触角变化），判读要留容差带。

### 齿轮

$$f_{GMF}=z\cdot f_r\quad(z=\text{齿数})$$

- 边带**间隔** = 哪根轴的转频 → 定位到**哪根轴上的齿轮**
- 边带**形态**（对称性、数量、幅度分布）→ 反映故障性质
- 常伴**边带簇 + GMF 谐波族 + 幅值调制**，与轴承故障的"纯谐波族"区分开

### 电机与其他

- **2× 线频**（100/120 Hz）：电磁力、气隙不均、绕组问题
- **滑差频率 $s f_r$ / 极通过频率**边带环绕 1×：转子条、断条
- **叶片通过频率 BPF** $=z_{叶片}\times f_r$：风机、泵
- 皮带频率：带轮直径比相关的次谐波

**价值在"先验"**：公式来自几何运动学和轴承手册，换台机器、换数据集照样成立——可解释、可迁移、可交叉验证。

## 三、第三件：包络解调（把坐标从噪声里抬出来）

> **②给出"要找什么频率"，③负责"把它从高频共振带里挖出来"。**

固定流程：**带通选共振带 → Hilbert 取包络 → 对包络做 FFT → 包络谱**。产出横轴单位为 Hz，峰位置直接对齐②算出的 $f_{BPFO}$ 等。

### 数学骨架

展开调制信号后取正频率部分：

$$X_+(f)=\frac{A_0}{2}\delta(f-f_c)+\sum_k\frac{A_k}{4}\Big[\delta(f-f_c-kf_i)+\delta(f-f_c+kf_i)\Big]$$

即**原始频谱 = 一根位于 $f_c$ 的载波 + 对称分布在两侧、间隔 $f_i$ 的边带梳**。"解调"就是把这把梳子整体从 $f_c$ 搬回 0 Hz → 边带摊开成 $f_i,2f_i,3f_i\dots$ 的清晰谱线。

**AM 收音机类比**：载波 1 MHz 电台 / 消息 20 Hz–20 kHz / 手段 二极管+RC 检波 —— 与载波 2–20 kHz 共振 / 消息 10–500 Hz 冲击率 / 手段 Hilbert 包络，**同一套数学**。

### Hilbert 解析信号

$$\hat{x}(t)=x(t)*\frac{1}{\pi t},\qquad x_a(t)=x(t)+j\hat{x}(t)=A(t)e^{j\varphi(t)}$$

- 包络 $A(t)=\sqrt{x^2+\hat{x}^2}$
- 瞬时相位 $\varphi(t)=\arctan(\hat{x}/x)$
- 瞬时频率 $\frac{1}{2\pi}\frac{d\varphi}{dt}$

频域实现极简：$H(f)=-j\,\mathrm{sgn}(f)$（幅度不动，相移 90°）；离散做法是 FFT → 负频率置零、正频率乘 2 → IFFT → 取模。

```python
import numpy as np
from scipy.signal import butter, filtfilt, hilbert

y = filtfilt(*butter(4, [f_lo, f_hi], 'bandpass', fs=fs), x)  # ① 带通
env = np.abs(hilbert(y))                                       # ② 解析信号取模
env = env - env.mean()                                         # ③ 去直流
spec = np.abs(np.fft.rfft(env * np.hanning(len(env))))         # ④ 包络谱
```

### 为什么必须先带通（成败关键）

Hilbert 取包络精确的前提是 **Bedrosian 乘积定理**：$A(t)$ 与 $\cos(2\pi f_c t)$ 的频谱支撑集不重叠。裸信号频谱连续铺开，不满足条件 → 直接取包络会剧烈抖动、无物理意义。**带通不是可选项，是前提。**

带宽是双向约束：

- **下限**：$B\gtrsim 2Kf_i$（$K$ 取 3–5 阶有效谐波），否则高阶边带被滤掉
- **上限**：不能宽到混进其他结构模态、齿轮啮合、电磁干扰
- **前提**：共振模态带宽 $f_c/Q$ 要大于梳子跨度，否则调制模型本身近似失效

**自动选带**：Antoni 的**谱峭度**（STFT 估计）：

$$\mathrm{SK}(f)=\frac{\big\langle|X_w(t,f)|^4\big\rangle_t}{\big\langle|X_w(t,f)|^2\big\rangle_t^{2}}-2$$

| 信号类型 | SK 值 |
|---|---|
| 纯正弦（平稳确定性） | −1 |
| 平稳高斯噪声 | 0 |
| 瞬态冲击（**我们要的**） | > 0 |

**Fast Kurtogram**（Antoni 2007）用 1/3-二叉树滤波器组在 (中心频率, 带宽) 平面扫描，取 SK 最大处作为带通参数，把 $O(N^2)$ 搜索降到近似 $O(N\log N)$。

### 取包络之后的变体

| 方法 | 要点 |
|---|---|
| **平方包络谱 SES** | 循环平稳视角下更优；抖动产生的宽带"基座"对平方包络不敏感，离散谱线更锐利。现代算法默认选择 |
| **Teager 能量算子 TEO** | $\Psi[x_n]=x_n^2-x_{n-1}x_{n+1}$，无需 FFT、计算量极小，适合在线/嵌入式；抗噪差 |
| **倒谱** | 对**对数谱**再做 FFT，$\log|X|=\log|H|+\log|E|$ 把卷积变加法 → 边带族变成倒频率 $T_i=1/f_i$ 处的尖峰。带通难做时的保底 |
| **MED / MOMEDA** | 解卷积锐化冲击（MED 最大化峭度，MOMEDA 瞄准指定周期 $T$），常放在带通**之前**以提高峭度图选带的可靠性 |
| **循环谱 / 谱相干** | 直接估计二维 $S_x^\alpha(f)$ 或 $\gamma_x^\alpha(f)$；包络解调只是其在 $f\approx f_c$ 处的**一维切片**。Fast Spectral Correlation 使其可算。**Infogram** 则把峭度换成平方包络谱负熵，专治"有冲击但不峭" |

工业界商业实现同族：**冲击脉冲法 SPM**（~32 kHz 谐振测 dB）、**高频共振技术 HFRT**、**共振解调**——名字不同，内核都是"在共振带上解调包络"。

### 参数与常见坑

| 坑 | 表现 | 对策 |
|---|---|---|
| 带通选错 | **头号失败原因**，包络谱一片平 | 谱峭度/峭度图/Infogram，别手拍 |
| 低通截止频率 | 太高残留载波、太低削掉高阶谐波 | 截止 $<f_c$，且能过 3–5 阶 $f_i$ |
| Hilbert 端点效应 | 首尾包络发散 | 镜像延拓/加窗；Hilbert 是全局算子，非因果 |
| 离散干扰谱线 | 50 Hz、邻机、啮合也在包络谱出峰 | 看是否成**谐波族**，孤立线一律排除 |
| 滚动体滑移 | 真实 BPFO 与公式差 1–2%，高阶峰变钝/劈裂 | 允许容差；用阶次跟踪拉直 |
| 速度波动 | 整片包络谱峰被抹平 | 角域重采样 → 阶次域 |
| 早期故障太弱 | 看不见 | 同步平均、延长采样、上 AE |
| 采样率不足 | 根本没采到共振带 | $f_s$ 覆盖 $f_c$ 的 2–3 倍，常需 10–50 kHz+ |

**降采样技巧**：带通后解析信号的复包络带宽 $\le B/2$，可大幅降采样再算包络谱，计算量降一两个数量级。

### 包络谱判读规则

横轴单位 Hz，核心原则是**找"谐波族"而不是找单根线**：

| 现象 | 推断 |
|---|---|
| $k f_{BPFO}$ 谐波族 | 外圈故障 |
| $k f_{BPFI}$ 谐波族 **+ 两侧 $f_r$ 间隔边带** | 内圈故障 |
| $k f_{BSF}$，常伴 $f_{FTF}$ 边带 | 滚动体故障 |
| $f_{FTF}$ 及谐波 | 保持架故障 |
| $k f_{mesh}$ 及 $f_r$ 边带 | 齿轮故障（边带间距对应哪根轴，就坏在哪根轴上） |
| 1× 转频高 | 不平衡 |
| 2× 转频高 | 对中不良 / 轴弯曲 |
| 大量转频谐波 | 机械松动 |

峰形态也要看：外圈峰谐波能延伸到很高阶且锐利；内圈峰到 3–4 阶后开始模糊（调制 + 滑移）；只有一根孤立线且不和谐，基本是干扰。

## 四、三件套的边界：什么时候会失效

| 假设 | 失效场景 | 后果 | 补丁 |
|---|---|---|---|
| 转速恒定 | 变工况、启停、负载波动 | 谱线漂移、峰被抹平 | ④阶次跟踪 |
| 线性叠加 | 碰摩、松动、干摩擦、裂纹 | 出现谐波/亚谐波/分叉，模型崩 | 时域波形、轨道图、小波、非线性动力学 |
| 冲击周期固定 | 滚动体滑移、随机载荷 | 峰展宽、阶次模糊 | 循环平稳方法、相干平均 |
| 结构共振稳定 | 温度漂移、装配变化 | 共振带迁移，带通失效 | 自适应选带、谱峭度在线跟踪 |
| 参数已知 | 缺轴承型号、拆装过 | ②算不出来 | 数据驱动反推、序列号反查 |
| 信噪比足够 | 极早期、强背景 | 地平线下看不见 | 同步平均、AE、解卷积、长时采样 |

**一句话**：三件套是**线性、平稳、参数已知**世界里的最优解；出了这个假设域，它退化成"参考基线"而非"结论"。

## 五、与 AI 的关系

1. **提供坐标系**：输出物理可解释的坐标（阶次、BPFO、边带）；AI 的"异常分数"没有这层坐标，无法回答"坏在哪"。
2. **提供归纳偏置**：把"频率来自几何公式"注入模型，能极大降低对标注数据的依赖——工业故障样本本来就不平衡且昂贵。
3. **前端决定后端上限**：信号没洗干净，模型只是在噪声上过拟合；带通选错一次，后端再复杂也救不回来。
4. **分工是"前/后"而非"旧/新"**：
   - 前端（三件套 + ④）：信号调理、坐标定位、非平稳归一化
   - 后端（数据驱动）：变工况自适应、非线性残余、多源融合、剩余寿命预测、在线更新

## 六、完整流程

```
传感器 → IEPE供电 → 抗混叠 → A/D (fs ≥ 2.56·fmax)
   ↓  ①  原始波形 + 时域指标筛查 (RMS / 峭度 / CF)
   ↓  ②  算特征频率表 (fr, BPFO, BPFI, BSF, FTF, GMF…)
   ↓      谱峭度 / 峭度图 自动选共振带
   ↓  ③  带通 → Hilbert 包络 → 包络谱 → 核对谐波族与边带
   ↓  ④  (变转速时) 角域重采样 → 阶次域
   ↓  判读 → 故障部位 + 严重程度
   ↓  后端：趋势跟踪、剩余寿命、在线自适应
```
