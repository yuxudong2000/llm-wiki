## 一、Conv-AE / CNN-AE ——「换骨架成卷积」

### 机制：先把序列"画成图片"，再用视觉网络看

```
一维波形 x(t)
    ↓  短时傅里叶变换 STFT（或 CWT 小波变换）
频谱图（横轴时间，纵轴频率，每个格子是能量值）
    ↓  当成一张"图像"，喂给 2D 卷积网络
瓶颈 → 解码 → 重建频谱图
    ↓
重构误差
```

STFT：把一维信号切成很多小段，每段做一次 FFT，再按时间顺序拼起来：

$$X(t,f)=\int x(\tau)\,w(\tau-t)\,e^{-j2\pi f\tau}\,d\tau$$

（$w$ 为窗函数）——结果是一个二维矩阵，横轴时间、纵轴频率、格值是能量，即「频谱图（时间×频率）」。有了这个二维结构，就能直接套用图像识别那套 2D CNN。

图里延续 LSTM-AE 那份笔记同样的"软件说法"翻译：

> 软件的说法：**把一维信号画成一张图片，再拿图像识别那套网络去跑。**

### 什么是"能量"（频谱图里格子的数值）

STFT 输出 $X(t,f)$ 是**复数**，信号处理里说的"能量"通常取**幅度平方**（或直接取幅度）：

$$E(t,f)=|X(t,f)|^2$$

含义：**在时刻 $t$ 附近这一小段窗口内，信号里频率为 $f$ 的成分振动得有多"猛"**。

**为什么原始波形没有这个概念**：原始一维波形每个点只是**振幅**（正负都有），只有时间、幅值两轴，是一条线，画不成二维图。STFT 把"这一小段时间窗口里的波形"拆解成一堆不同频率正弦波的叠加（傅里叶变换本质），再告诉你**每个频率成分各自贡献了多少"份量"**——这个份量就是能量。

**类比**：原始波形像"某一时刻空气里混着好几种乐器的声音，只给你一条振幅曲线"；做完 STFT，相当于把这段声音拆成"小提琴多响、鼓多响、长笛多响"——每种乐器（每个频率）对应一个响度数值，就是能量。

**放到轴承故障场景**：外圈故障会在 $f_{BPFO}$ 上持续、周期性释放能量 → 频谱图上表现为**某条固定频率的横线颜色格外深（数值格外高）**，且随时间（多个冲击周期）重复出现。卷积核滑过这个"固定位置、局部一小块、数值突出"的区域，相当于在图像里"认出一个亮斑/一条纹理"——即图里说的**"轴承敲击在谱上是固定位置的一个峰"**。

**与包络解调的关系（避免混淆）**：

| | 包络解调（第③步） | Conv-AE 用的 STFT 频谱图 |
|---|---|---|
| 是否带通预筛选 | 是，先锁定共振带 | 否，直接对原始/初步处理信号做变换 |
| 输出维度 | 一维（包络谱，横轴频率 Hz） | 二维（时间×频率矩阵） |
| 是否带物理先验 | 强（专为挖故障调制信息设计） | 弱（通用时频表示，不带假设） |

两者本质都是"把看不出规律的振幅曲线转换成频率维度上能量分布"，但包络解调是专门的、带先验的流程；STFT 频谱图是通用表示，能喂给 CNN纯粹因为它长成了"图片"形状——这也是它"长时依赖弱"的根源：CNN 不知道"这是振动信号"，只知道"这是一张有局部纹理的图片"。

### 强弱点，都由卷积核感受野决定

- **强在局部模式**：小卷积核在频谱图上滑动，本质是找"局部一小块区域内的固定模式"。轴承敲击在谱上是**固定位置的一个峰**，正是卷积核擅长识别的形状——跟图像识别里"找一只眼睛"是同一种操作。
- **弱在长时依赖**：卷积感受野局部且固定，堆叠再多层能看到的时间跨度也有限。若异常是**跨越很长时间尺度的趋势性变化**（退化过程本身，而非某个瞬间冲击），CNN 天然不擅长——这正是 LSTM/Transformer/SSM 类骨架的优势所在，两者互补。

图里配的示意图：小卷积核在频谱图上"滑"，抓住虚线框标出的一小块局部区域，输出侧直接写结论——**"感受野有限 ⇒ 长时依赖弱"**。

### 实测态度表态

> **我们打过：** 边坡报告里的 B8（2025 SOTA）—— 一条边坡过度触发 37 次，另一条漏了 7–13 暴雨。

这是**竞品实测评价**，不是通用技术结论：某个 2025 年发布、边坡监测领域号称 SOTA 的方法被拿来实测对比，暴露两个典型问题——

- **过度触发（误报）**：一条边坡触发 37 次，暗示阈值/模型对"正常波动"容忍度不够，对应上一份笔记讲的"域漂移导致误报率飙升"；
- **漏报**：另一条边坡漏掉 7–13 号几场暴雨事件，说明对**长期趋势性**触发信号识别不足——恰好印证"CNN 长时依赖弱"这个技术弱点，在真实边坡监测场景里变成具体的漏报案例。

> 这两个数字是内部竞对评测结论，未说明测试数据集规模、评测协议、B8 具体是什么方法。适合内部决策参考，不宜直接作为通用技术结论对外引用。

## 二、GNN 图神经网络 ——「换的是『谁和谁相关』」

开篇特意做框架修正：

> **换的不是骨架，是「谁和谁相关」**

前面 Conv-AE 换的是"怎么处理单条信号内部结构"（时间×频率的局部模式），GNN 换的是**"多个测点之间要不要互相看"**——这是全新的建模维度，不只是"换个网络层"。

### 机制：把多测点系统建模成图

```
节点 = 测点（每个传感器/每个监测位置）
边   = 测点之间的相关性（物理连接、空间相邻、历史统计相关等）
```

正常情况下，物理上关联的测点会**一起动**——比如一段边坡上相邻的几个监测点，正常情况下振动/位移应呈现相近模式（同一片山体、同一场降雨、同一次地震的影响）。

**异常判定逻辑变了**：不是看"某个测点自己的数值是否越限"，而是看"某个测点是否脱离了邻居的共同模式"。图里示意：四个节点三个正常联动（箭头方向一致），一个红色节点**脱离了群体行为**，判定异常。关键句：

> 不是看它自己越不越限。

### 具体方法

**MTAD-GAT**（Multivariate Time-series Anomaly Detection via Graph Attention）、**GDN**（Graph Deviation Network）——共同思路：先学出"正常时测点间应该有的相关性图结构"，推理时看新数据在这张图上算出来的偏差有多大。本质仍是"重构式"或"预测式"异常检测，只是把单变量的"重建序列"换成了"重建/预测图结构上的关联模式"。

### 场景匹配度

> **对 SHM 最相关** —— 桥隧边坡本来就是多测点网络。

SHM = Structural Health Monitoring（结构健康监测）。桥梁、隧道、边坡监测的天然特点是**部署了一整片传感器网络**，测点间本身有物理拓扑关系（同一段隧道的相邻传感器、同一座桥不同截面的应变计）——GNN 能直接利用这个结构，而 Conv-AE/LSTM-AE 只能各测点独立跑，浪费了"测点间关联"这个额外信息。

### 坦诚缺口

> **我们没测过。对方问起来就说没跑过，回去给。**

三格里唯一明确承认没做实测对比的一格，并给出标准应答话术。诚实标注是好习惯，但也说明这条路线在材料成型时是**技术缺口**，非已验证能力。

## 三、Mamba / SSM ——「换骨架成『固定状态递推』」（本页仅提纲，留待下页）

### 一句话机制

> 不存历史，只维护一份固定大小的状态。

Mamba 类**状态空间模型（State Space Model, SSM）**与 LSTM 的核心区别：

| | LSTM | SSM/Mamba |
|---|---|---|
| 状态更新 | 非线性门控（$\sigma,\tanh$），当前输入与上一状态复杂交互 | **线性**递推 $h_t=Ah_{t-1}+Bx_t$，结构更接近经典控制论状态空间方程 |
| 训练方式 | 时间步严格串行 | 可用**并行扫描（parallel scan）**或卷积核形式重写，训练可并行 |
| 长序列表现 | 长了退化（梯度问题、瓶颈饱和） | 专门设计处理很长序列，$A$ 矩阵谱结构决定记忆衰减方式，可调更均匀 |

字面上"不存历史，只维护固定大小状态"和 LSTM 隐藏状态很像（都是固定维度），**真正区别在状态更新的数学形式**——LSTM 靠门控网络学习"记住什么忘记什么"，是黑箱式的；SSM 的记忆特性由状态转移矩阵 $A$ 的结构直接决定，是**可解释、可设计**的。

### 「可推导版」的含义

> 我们这条线用的是它的可推导版（**Legendre / LMU**）。

**LMU = Legendre Memory Unit**：一类专门设计的 SSM 变体，状态转移矩阵 $A$ 用**勒让德多项式（Legendre polynomials）**推导，让隐藏状态成为"输入信号在过去一段时间窗口内的最优多项式逼近"，数学上有明确的正交基展开解释，不像原始 Mamba 那样靠数据学出一个不透明的 $A$。

图里特意点出"可推导"这个词，暗示选型逻辑是：**要一个数学上讲得清楚、能给客户解释清楚"为什么记得住/为什么忘得掉"的版本**，而不是纯粹靠深度学习黑箱堆参数量刷分。

### 这一格的分量

> 这一格是我们自己在用的东西，要讲得比别的格更熟。

说明这张图的信息密度分布不均匀——Conv-AE 和 GNN 更像"友商/竞品打法的归类归档"，Mamba/LMU 才是"自己的核心技术资产"。这解释了为什么细节留白、放到下一页单独讲——不是内容不够，是分量重到需要单独一页。

## 四、整体定位：三种不同的归纳偏置

延续上一张图的分析框架，这张图仍是**竞品/自身技术路线的归档卡片**，三个格子的证据强度呈明显梯度：

| 格子 | 态度 | 证据强度 |
|---|---|---|
| Conv-AE | 打过，给出具体实测数字（37 次误报、漏 7–13 暴雨） | 有实测，暴露弱点 |
| GNN | 没测过，坦诚承认 | 无实测，理论匹配度高 |
| Mamba/LMU | 自己的核心线，要讲得最熟 | 下一页才展开，这里先占位 |

三格拼起来，构成"骨架"维度里**三种完全不同的归纳偏置**（对"异常长什么样"的三种假设）：

- **Conv** 假设异常是**局部、固定形状**的模式（空间局部性）；
- **GNN** 假设异常是**打破了测点间关系**的模式（关系局部性）；
- **SSM/Mamba** 假设异常是**打破了一份被压缩记住的长期状态**的模式（时间上的全局压缩）。

三者不是谁比谁强，而是对"异常长什么样"给出三种不同假设——延续上一张图末尾"不比精度、比运维成本"的立场：选骨架的标准是"跟场景假设匹不匹配"，而非刷榜。

## 五、知识点清单

1. **STFT / 时频图**：$X(t,f)=\int x(\tau)w(\tau-t)e^{-j2\pi f\tau}d\tau$，把一维振幅信号转为二维时间×频率能量矩阵
2. **能量 = 幅度平方** $E(t,f)=|X(t,f)|^2$，与包络解调（一维、带先验）的区别
3. **CNN 归纳偏置**：局部感受野 → 强局部模式（固定位置的峰）、弱长时依赖
4. **图神经网络（GNN）建模多测点系统**：节点=测点，边=相关性；异常判据从"自己越限"变为"脱离邻居模式"
5. **MTAD-GAT / GDN**：图注意力/图偏差网络在多变量异常检测中的应用
6. **SHM（结构健康监测）**天然的多测点网络特性与 GNN 的场景适配
7. **状态空间模型 SSM**：线性状态递推 $h_t=Ah_{t-1}+Bx_t$，与 LSTM 非线性门控的对比；可并行训练
8. **LMU（Legendre Memory Unit）**：用勒让德多项式推导状态转移矩阵，可解释的记忆机制
9. **骨架选型的本质是选归纳偏置**：局部性 vs 关系性 vs 长期压缩状态，三者对应不同"异常"定义
