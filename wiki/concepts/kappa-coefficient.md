# Kappa系数（评测一致性指标）

## 定义

Kappa系数是衡量**多名评测员之间一致性**的统计指标，核心贡献是把"碰巧一致"的部分扣掉，只保留真实一致性。

$$\kappa = \frac{P_o - P_e}{1 - P_e}$$

- $P_o$：实际一致率（两人给出相同判断的比例）
- $P_e$：随机期望一致率（碰巧一致的概率）
- $\kappa$：扣除随机因素后的真实一致性

## 为什么不能只看"表面一致率"

假设两人评测结果有85%一致，听起来很高。但如果随机情况下本来就有51%概率一致，真实的"因判断标准一致而产生的一致"只有：

$$\kappa = \frac{0.85 - 0.51}{1 - 0.51} \approx 0.69$$（较强一致性）

如果随机一致率是80%，那85%的表面一致率意义就很小了：

$$\kappa = \frac{0.85 - 0.80}{1 - 0.80} = 0.25$$（较弱一致性）

## Kappa 解读标准

| Kappa值 | 一致性 | AI评测建议 |
|---------|--------|-----------|
| < 0 | 比随机还差 | 评测无效，重做 |
| 0 ~ 0.20 | 很弱 | 评测结论完全不可信 |
| 0.21 ~ 0.40 | 较弱 | 不建议作为决策依据 |
| 0.41 ~ 0.60 | 中等 | 可用，需说明局限 |
| 0.61 ~ 0.80 | 较强 | 结论可信 |
| 0.81 ~ 1.00 | 很强 | 评测标准非常清晰 |

## 三种 Kappa 的选择

| 场景 | 工具 |
|------|------|
| 恰好2名评测员，多分类 | Cohen's Kappa |
| ≥2名评测员，同一批数据 | Fleiss' Kappa（AI评测最常用） |
| 2名评测员，有序等级（1~5分） | Weighted Kappa |

**AI评测实践**：多人评同一批数据 → 直接用 Fleiss' Kappa。

## 在 AI 评测中的应用

> [!quote]
> 不要只说"人工评测觉得A比B好"，还要证明评测标准稳定（比如看评测员之间的一致性）。否则这个结论可能只是主观偏好。
> Source: [[sources/kappa系数]]

- Kappa < 0.4：评测结论不可信，需要修订评分标准、增加样例、进行评测员校准训练
- Kappa ≥ 0.6：结论具备较好的可信度
- 发布评测报告时，应同时报告 Kappa 系数作为评测质量的证明
