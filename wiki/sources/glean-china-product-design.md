# 中国版Glean企业知识系统产品设计

## TL;DR

- 核心价值主张：打破信息孤岛，跨应用语义检索+问答，答案带来源引用，安全可控
- 技术架构：多源连接器 + 向量检索（Milvus等）+ 知识图谱 + RAG问答引擎 + Agent编排
- 中国化关键点：国产云适配（华为云/阿里云）、数据本地化合规、飞书/钉钉/企微集成、政务/金融/制造先行
- 差异化护城河：企业级图谱（多跳检索）+ 严格权限体系 + 深度集成形成的语义索引积累
- 商业模式：按用户数/检索量订阅 + 专业服务费（定制集成、培训）

## 核心论点

- **目标人群**：知识工作者（研发/销售/客服/新员工/管理层），共性痛点是"信息孤岛+检索低效+知识流失"
- **核心能力层次**：统一搜索问答 → 文档综合分析 → 知识图谱导航 → AI助手创作 → 自动化Agent
- **权限感知检索**：检索阶段通过Filter机制过滤无权限文档，安全性是企业客户核心关切
- **与国内竞品差异**：飞书/钉钉侧重聊天助手，本产品强调全公司级知识图谱+多跳推理+工作流自动化
- **实施路线**：MVP（多源文档接入+语义检索）→ 增强上下文推理 → Agent自动化 → 纵深行业适配
